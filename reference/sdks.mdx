---
title: SDKs
description: Assign functions and record JSON outcomes at runtime.
---

SDKs consume running experiments. They do not create, edit, start, or stop them.
Local SDKs can use the saved `ssp login`. Deployed applications use `SSP_API_KEY`.
Set `STATESPACE_URL` to select the backend.

## Function execution

Assign a subject, execute its published function, and record an outcome.

<CodeGroup>
```python Python
import statespace

with statespace.init("rank-v2") as run:
    rank = run.get_function(
        "u_42", context={"country": "US"}, default=lambda items: items
    )
    result = rank([3, 1, 2])
    run.log("u_42", {"relevance": 0.7, "result": result})
```

```typescript TypeScript
import { init } from "@statespace-tech/sdk";

const run = await init("rank-v2");
try {
  const rank = run.getFunction("u_42", {
    context: { country: "US" },
    default: (items) => items,
  });
  const result = await rank([3, 1, 2]);
  run.log("u_42", { relevance: 0.7, result });
} finally {
  await run.close();
}
```

```go Go
ctx := context.Background()
run, err := statespace.Init(ctx, "rank-v2")
if err != nil {
    log.Fatal(err)
}
rank, err := run.GetFunction("u_42", statespace.FunctionOptions{
    Context: statespace.Object{"country": "US"},
    Default: func(input any) (any, error) { return input, nil },
})
if err != nil {
    log.Fatal(err)
}
result, err := rank(ctx, []int{3, 1, 2})
if err != nil {
    log.Fatal(err)
}
if _, err = run.Log("u_42", statespace.Object{"relevance": 0.7, "result": result}); err != nil {
    log.Fatal(err)
}
if err = run.Close(); err != nil {
    log.Fatal(err)
}
```
</CodeGroup>

The callable uses the default for control or a stopped experiment. Without a
default, Python returns `None`, TypeScript returns `null`, and Go returns `nil`.
The subject's assignment remains stable within the session. Wasm runs locally;
the backend does not execute the customer function.

## Runtime limits

Execution defaults to a five-second timeout. Python uses seconds for a custom
`timeout`, TypeScript uses milliseconds, and Go uses `time.Duration`.
Guest linear memory defaults to 256 MiB per memory. Set
`STATESPACE_MAX_MEMORY_BYTES` to change that limit.

Function failures raise or return a function error and record a
`function_execution` outcome. A timeout reports a function timeout error.
Validate the input and handle execution errors in the application.

## Delivery

The SDK batches runs and JSON outcomes in memory. Each complete serialized event
must fit in 64 KiB. Oversized events fail before entering the queue. The backend
accepts an event after committing its account outbox; SQS and the worker write
the final event rows asynchronously.

Close short-lived sessions and handle delivery failures.

<CodeGroup>
```python Python
run.close()
```

```typescript TypeScript
await run.close();
```

```go Go
if err := run.Close(); err != nil {
    log.Fatal(err)
}
```
</CodeGroup>

Permanent HTTP rejections propagate through flush or close. The SDK retries
transient failures with the same event IDs. An in-memory queue does not survive
application process loss. The backend retains raw events for 90 days by default
and rejects writes when the account's 10 GiB event quota is full.
