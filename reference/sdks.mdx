---
title: SDKs
description: Assign subjects, read parameters, and record outcomes at runtime.
---

SDKs consume running experiments. They do not create, change, start, or stop them.
Local SDKs can use the saved `ssp login`. Deployed applications use `SSP_API_KEY`.
Set `STATESPACE_URL` to select the backend.

## Groups

Get an experiment once, assign each subject, and read the group's parameters. Every read takes the application's current code or value as the default.

<CodeGroup>
```python Python
import statespace

experiment = statespace.experiment("rank-v2")
group = experiment.assign("u_42", context={"country": "US"})
rank = group.function("ranker", current_rerank)
results = rank([3, 1, 2])[: group.value("top_k", 20)]
experiment.log("u_42", "click", {"position": 1})
```

```typescript TypeScript
import { experiment } from '@statespace-tech/sdk';

const ranking = await experiment('rank-v2');
const group = ranking.assign('u_42', { context: { country: 'US' } });
const rank = group.function('ranker', currentRerank);
const results = (await rank([3, 1, 2])).slice(0, group.value('top_k', 20));
ranking.log('u_42', 'click', { position: 1 });
```

```go Go
ranking, err := statespace.Load(ctx, "rank-v2")
group := ranking.Assign("u_42", map[string]any{"country": "US"})
rank := statespace.Function(group, "ranker", currentRerank)
results, err := rank(ctx, []int{3, 1, 2})
results = results[:min(len(results), statespace.Value(group, "top_k", 20))]
ranking.Log("u_42", "click", map[string]any{"position": 1})
```
</CodeGroup>

`assign` records one run. The group's name is the group, `control`, or empty when the subject is not in the experiment. A subject is outside the experiment while it is not running, when the configuration is stale, and when the eligibility rule excludes it.

## Defaults and failures

A read returns the default for control, for parameters the group does not set, and when the group's value cannot be used. The SDK then records a `statespace.error` outcome with the parameter and the reason.

| Reason | Cause |
| --- | --- |
| `type` | The value's JSON type differs from the default's, or a function was read as a value |
| `failed` | The function trapped or its component could not be loaded |
| `timeout` | The function exceeded its time limit, five seconds by default |
| `invalid-json`, `invalid-output` | The input or output was not valid JSON for the function |

Reads never raise because of Statespace. Only loading an experiment fails, for an unknown experiment or an invalid key.

## Runtime limits

Functions run locally without filesystem, network, or environment access. Each call gets a fresh instance. Guest linear memory is limited to 256 MiB unless `STATESPACE_MAX_MEMORY_BYTES` sets another limit.

<CodeGroup>
```python Python
score = group.function("scorer", default_score, timeout=0.05)
```

```typescript TypeScript
const score = group.function('scorer', defaultScore, { timeoutMs: 50 });
```

```go Go
score := statespace.Function(group, "scorer", defaultScore, statespace.WithTimeout(50*time.Millisecond))
```
</CodeGroup>

## Delivery

SDKs queue runs and outcomes and send them in batches of up to 100. Transient failures are retried. Each serialized event must fit in 64 KiB. Flush before a short-lived process exits.

<CodeGroup>
```python Python
statespace.flush()
```

```typescript TypeScript
await flush();
```

```go Go
err := statespace.Flush(ctx)
```
</CodeGroup>
