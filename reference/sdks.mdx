---
title: SDKs
description: Assign subjects and record JSON outcomes at runtime.
---

SDKs consume remote experiments. They do not create, edit, start, or stop them.

<CodeGroup>
```python Python
import statespace

with statespace.init("rank-v2") as run:
    config = run.get_config("u_42", context={"country": "US"})
    reranker = config.get("reranker")
    run.log({"relevance": 0.7})
```

```typescript TypeScript
import { init } from "@statespace-tech/sdk";

const run = await init("rank-v2");
const config = run.getConfig("u_42", { country: "US" });
const reranker = config.reranker;
run.log({ relevance: 0.7 });
run.close();
```

```go Go
run, err := statespace.Init(context.Background(), "rank-v2")
defer run.Close()
config, err := run.GetConfig("u_42", statespace.Object{"country": "US"})
reranker := config["reranker"]
_, err = run.Log(statespace.Object{"relevance": 0.7})
```
</CodeGroup>

## Assignment

The SDK evaluates CEL against the supplied JSON `context`. Eligible subjects use a stable SHA-256 bucket. Ineligible subjects are unassigned and receive `{}`.

```text
bucket = first 53 bits of SHA-256(assignment_salt + ":" + subject_id) / 2^53
```

## Caching

Each SDK refreshes active configuration every 60 seconds. It uses the last valid configuration for up to 48 hours during an outage. It then stops new assignments and returns `{}`.

## Delivery

Assignment records and JSON outcomes use an in-memory queue. The SDK sends batches in the background. Flush short-lived processes before exit.

<CodeGroup>
```python Python
statespace.flush()
```

```typescript TypeScript
await flush();
```

```go Go
err := run.Close()
```
</CodeGroup>
