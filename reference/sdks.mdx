---
title: SDKs
description: Review runtime initialization, assignment, caching, and delivery.
---

The Python SDK creates experiments at runtime, assigns subjects, and records arbitrary JSON outcomes. A read-write token identifies the account database.

## Load YAML

Load and validate one YAML definition.

```python
import statespace

definition = statespace.load("experiment.yaml")
```

`load()` returns a dictionary that can be passed directly to `init()`.

## Define Python objects

Use the public Pydantic models when the definition belongs in Python code.

```python
experiment = statespace.Experiment(
    name="rank-v2",
    description="Test reciprocal rank fusion.",
    assignment="user_id",
    groups=[
        statespace.Group(
            name="treatment",
            weight=0.2,
            config={"reranker": "rrf"},
        )
    ],
)
```

`Group.config` can contain live Python objects. The SDK keeps these objects in the process and uploads only their JSON-compatible projection.

## Initialize a run

Initialize with the loaded dictionary.

```python
with statespace.init(**definition) as run:
    config = run.get_config("u_42")
    run.log({"relevance": 0.7})
```

Pass the Pydantic model directly when the definition is in Python code.

```python
with statespace.init(experiment) as run:
    config = run.get_config("u_42")
    run.log({"relevance": 0.7})
```

The first call creates and starts an absent experiment. The SDK accepts an identical definition and rejects a conflict with the same name.

## Assign a subject

Pass one stable assignment value and optional pre-treatment context.

```python
config = run.get_config(
    "u_42",
    context={"country": "US", "device": "desktop"},
)
```

`get_config()` returns an immutable mapping. Use an explicit application default for each optional runtime value.

## Record an outcome

Pass exactly one dictionary to `log()`.

```python
run.log({"relevance": 0.7, "latency_ms": 84})
```

Call `get_config()` before each `log()` call. One `Run` can process many subjects.

## Refresh the definition

The SDK polls experiment metadata every 60 seconds by default.

| Condition | Behavior |
| --- | --- |
| Refresh succeeds | Use the current definition for later assignments. |
| Refresh fails | Keep the last valid definition and expose `run.refresh_error`. |
| Experiment stops | Reject new configuration requests. |

## Flush and close

The context manager flushes queued records and closes background resources. Use the explicit lifecycle when a framework controls shutdown.

```python
run = statespace.init(experiment)
try:
    config = run.get_config("u_42")
    run.log({"relevance": 0.7})
    run.flush()
finally:
    run.close()
```

`close()` is idempotent. Record identifiers remain stable across delivery retries.

<Warning>
  Do not ignore a final flush or close error. The error means that one or more records did not receive durable acknowledgement.
</Warning>
