title: SDKs
description: Review runtime assignment, caching, outcomes, and delivery interfaces.

Statespace SDKs evaluate cached manifests, apply stable assignments, and deliver experiment events. Use the same project and experiment reference in each language.

## Python SDK

Connect and record one run with Python.

```python
from statespace import Experiment

experiment = Experiment.connect(
    "atlas-search/rank-v2",
    token="ssp_rw_7j...",
)

run = experiment.run("user_42")
run.outcome("relevance", value=0.87)
experiment.close(timeout=10.0)
```

## TypeScript SDK

Connect and record the same run with TypeScript.

```typescript
import { Experiment } from "@statespace/sdk";

const experiment = await Experiment.connect("atlas-search/rank-v2", {
  token: "ssp_rw_7j...",
});

const run = experiment.run("user_42");
run.outcome("relevance", { value: 0.87 });
await experiment.close({ timeout: 10_000 });
```

## Local evaluation

The run method takes one stable assignment value and optional runtime metadata.

<Tabs>
  <Tab title="Python">
    Supply strata, context, or a forced quality-assurance group.

    ```python
    run = experiment.run(
        "user_42",
        strata={"country": "US"},
        context={"client_version": "3.4.0"},
        force=None,
    )
    ```
  </Tab>
  <Tab title="TypeScript">
    Supply the same runtime fields with an options object.

    ```typescript
    const run = experiment.run("user_42", {
      strata: { country: "US" },
      context: { client_version: "3.4.0" },
    });
    ```
  </Tab>
</Tabs>

The returned run includes `id`, `assignment`, `group`, `config`, `enrolled`, and `revision`.

## Manifest caching

| State | Behavior |
| --- | --- |
| Valid cached manifest | Evaluate locally. |
| New manifest available | Verify and replace the cache. |
| Refresh unavailable | Keep the last valid manifest. |
| No valid manifest | Return an SDK error. |

The default refresh interval is 60 seconds. Configure `STATESPACE_URL` only for a nonproduction endpoint.

## Event delivery

The SDK batches runs and outcomes in the background. Event identifiers make retries idempotent.

```python
experiment.flush(timeout=10.0)
experiment.close(timeout=10.0)
```

`flush()` waits for current events. `close()` flushes events and stops background work.

## Idempotency

Supply a run identifier when the application already has a stable request identifier.

```python
run = experiment.run("user_42", id="request_91")
```

Repeating the same accepted identifier does not create a second run.

## Error handling

SDK errors identify configuration, evaluation, and delivery failures separately.

```python
from statespace import StatespaceError

try:
    experiment.close(timeout=10.0)
except StatespaceError as error:
    report_delivery_failure(error)
```

Do not silently discard final delivery failures.
