---
title: Host
description: Review how ssp host runs processes, routes requests, and records events.
---

`ssp host` replaces an app's start command. It runs control and every variant of the app's running experiments as processes on private ports. A proxy on the public port assigns each request's subject and forwards the request.

```text
load balancer → ssp host :8080 → control           127.0.0.1:41022
                               → atlas-search@3    127.0.0.1:41023
```

## Flags

Start the host where the app's code is. Control runs in the current directory.

```shell
ssp host --app atlas \
  --listen 0.0.0.0:8080 \
  --command "gunicorn -b 127.0.0.1:{port} atlas:app" \
  --health /health \
  --trust-key "$SSP_PUBLIC_KEY" \
  --variant-env DATABASE_URL="$VARIANT_DATABASE_URL" \
  --capture stderr --capture http \
  --redact 'sk_live_\w+'
```

| Flag | Meaning |
| --- | --- |
| `--app` | The app whose running experiments to serve, or `STATESPACE_APP` |
| `--listen` | The public address. Defaults to `0.0.0.0:8080`, or `STATESPACE_LISTEN` |
| `--command` | How to start the app, with `{port}` for the port it must listen on at 127.0.0.1. It runs with `sh -c` |
| `--health` | A path that must answer 200 before a process gets traffic. Without it, a process is ready once its port accepts connections |
| `--trust-key` | A base64 public key whose signed variants may run. Repeat to rotate keys |
| `--max-variants` | How many variants run at once, besides control, 1 to 64. Defaults to 4 |
| `--stale-after` | Seconds to keep routing with the last configuration while Statespace is unreachable. Defaults to 300 |
| `--variant-env NAME=VALUE` | An environment variable that variants get and control does not. Repeatable |
| `--capture` | Also send `stdout`, `stderr`, or one row per `http` request. Repeatable |
| `--redact REGEX` | Replace matches in captured lines before they leave the machine. Repeatable |
| `--cache` | Where downloaded variants are kept, or `STATESPACE_CACHE` |
| `--local` | Run local directories unsigned, without Statespace |
| `--variant NAME=PATH` | A local variant, with `--local`. Repeatable |

The host needs a key with `runtime:read` and `events:write` in `SSP_API_KEY`.

## Processes

Each process gets the host's environment, then `--variant-env` for variants, then these variables.

| Variable | Value |
| --- | --- |
| `PORT` | The port to listen on at 127.0.0.1 |
| `STATESPACE_APP` | The app |
| `STATESPACE_VARIANT` | `control`, or the variant's name |
| `STATESPACE_VARIANT_VERSION` | The variant's version; unset for control |

The host never passes `SSP_API_KEY` to processes. Before a variant runs, the host checks its signature against `--trust-key`, downloads its bundle, checks its SHA-256, and unpacks it. A process that exits restarts with backoff, up to one minute. On `SIGTERM`, the host stops accepting connections, lets requests finish for up to 10 seconds, and stops every process group.

Variants run on the same machine as control, with the same operating system and libraries. Build them for it.

## Requests

For each request, the host finds the first running experiment whose slice contains the subject, checks eligibility, and picks the variant. It forwards the request with these headers, and removes any a client sent.

| Header | Value |
| --- | --- |
| `x-statespace-subject` | The subject ID, or the `ssp_sid` cookie |
| `x-statespace-variant` | The process serving the request |
| `x-statespace-experiment` | The experiment, when the subject is in one |

The host sets an `ssp_sid` cookie on a new visitor's first response. It accepts HTTP/1.1 and HTTP/2, streams request and response bodies, and passes WebSocket and other upgrades through. A request without a body that a variant fails to answer is retried on control.

A subject gets control, recorded as `variant-unavailable`, when its variant is starting, failing, or over `--max-variants`. Every subject gets control when the host has no configuration newer than `--stale-after`.

## Outcomes

A process reports an outcome by printing one JSON object on a line of standard output.

```json
{"statespace": "purchase", "subject": "u_42", "amount": 42, "currency": "USD"}
```

`statespace` names the outcome, and `subject` identifies the subject. Every other field becomes `data`. The host reads outcome lines without `--capture`, and passes every line through to its own output.

## Events

| Event | Sent |
| --- | --- |
| Runs: a subject's first routing, per experiment version and reason, every 30 minutes at most | Always |
| Outcomes printed by processes | Always |
| Lifecycle: started, ready, exited, stopped, failed | Always |
| Per-minute HTTP summaries and CPU and memory, per process | Always |
| Standard output and standard error lines | With `--capture stdout` or `--capture stderr` |
| One row per request: method, path, status, timing, and sizes | With `--capture http` |

Request headers and bodies are never sent. Events are buffered and sent in batches. When Statespace is slow or unreachable, the host drops events rather than delay the app.

## Local mode

Run local directories as variants, unsigned and without Statespace.

```shell
ssp host --local --command "python3 app.py {port}" --variant atlas-search=../new-ranking
curl -H 'x-statespace-variant: atlas-search' localhost:8080
```

The `x-statespace-variant` header chooses the process. Without it, control serves the request. `--local` cannot be combined with `--trust-key`.
