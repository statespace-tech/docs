The CLI prints successful results as JSON. It prints diagnostics on standard error.

## Authentication

Use account login for management commands.

```shell
ssp login
ssp account
ssp logout
```

## Experiments

Create `v1`, publish later immutable versions, and control which version runs.

```shell
ssp experiment create --file experiment.yaml
ssp experiment publish --file experiment.yaml
ssp experiment list
ssp experiment show --name rank-v2
ssp experiment start --name rank-v2 --version 2
ssp experiment stop --name rank-v2
ssp experiment delete --name rank-v2
```

Starting a new version stops new assignments to the prior running version.

## SDK tokens

Token secrets appear only in create responses.

```shell
ssp token create --name production
ssp token list
ssp token revoke --id tok_123
```

## PostgreSQL

Create credentials for a SQL client. Statespace has no server-side query endpoint: you
query your own database directly, with a credential that holds `SELECT` on the
`statespace` schema and nothing else.

```shell
ssp database credential create --name analyst
ssp database credential list
ssp database credential revoke --id dbc_123
```

```shell
psql "$STATESPACE_DATABASE_URL" -c 'SELECT * FROM statespace.logs LIMIT 20'
```

## Audit trail

Read the account's record of control-plane changes. Requires the `audit:read` scope.

```shell
ssp audit --limit 50
ssp audit --limit 50 --before 4821
```

Set `STATESPACE_ACCOUNT_TOKEN` for headless CLI and CI use. This value is an account session, not an SDK token.

```shell
export STATESPACE_ACCOUNT_TOKEN=ssp_account_...
```
