title: CLI
description: Review every public ssp command, option, and output convention.
---

The `ssp` CLI manages account access, tokens, layers, and experiment state. It prints structured YAML.

```text
ssp <resource> <action> [options]
```

## Account commands

| Command | Purpose |
| --- | --- |
| `ssp login` | Sign in with GitHub or Google. |
| `ssp logout` | Remove the saved account session. |
| `ssp account` | Show account usage, plan limits, and the database URL. |

`ssp account` has no subcommands. Sign-up creates one account database, which the CLI selects automatically.

## Token commands

| Command | Required options |
| --- | --- |
| `ssp token create` | `--name, -n` and `--access` |
| `ssp token list` | None |
| `ssp token revoke` | `--id` |

The `--access` option accepts `read-only` or `read-write`. Token creation prints the complete secret once.

## Experiment commands

| Command | Required options |
| --- | --- |
| `ssp experiment list` | None |
| `ssp experiment show` | `--name, -n` |
| `ssp experiment start` | `--name, -n` |
| `ssp experiment stop` | `--name, -n` |
| `ssp experiment delete` | `--name, -n` |
| `ssp experiment traffic set` | `--name, -n` and `--traffic` |

The SDK creates experiments at runtime. The CLI does not create or update their definitions.

## Layer commands

| Command | Required options |
| --- | --- |
| `ssp experiment layer create` | `--file, -f` |
| `ssp experiment layer update` | `--file, -f` |
| `ssp experiment layer list` | None |
| `ssp experiment layer show` | `--name, -n` |
| `ssp experiment layer delete` | `--name, -n` |

## Global options

| Option | Environment variable | Purpose |
| --- | --- | --- |
| `--endpoint` | `STATESPACE_URL` | Override the API endpoint. |
| `--account-token` | `STATESPACE_ACCOUNT_TOKEN` | Override the saved account session. |
| `--help` | — | Print command help. |
| `--version` | — | Print the installed version. |

## Output format

Every successful data command prints YAML. Errors use a nonzero exit status and write a concise message to standard error.

```yaml
id: acct_7j...
provider: github
login: atlas-search
plan: free
usage_bytes: 0
storage_limit_bytes: 1000000000
write_events_per_minute: 100
retention_days: 7
database_url: quack:atlas-search.db.statespace.app:443
```
