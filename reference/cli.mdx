title: CLI
description: Review the public ssp command surface.

Every command prints one JSON document. Errors print `{"error": "..."}` on standard error and exit with status 1.
Use `STATESPACE_URL` to select a local or hosted API.

## Authentication

Sign in through GitHub or Google, then approve the terminal's device code.

```shell
ssp login
ssp account
ssp logout
```

The saved session is shared with local SDKs. Use `SSP_API_KEY` for headless CLI
and deployed SDK access. Keep creation responses out of recorded logs.

## API keys

Create a runtime key for SDK configuration reads and event writes.

```shell
ssp key create --name production --preset runtime
ssp key list
ssp key revoke key_123
```

Secrets appear only in create responses. Store the returned secret in the
application's secret system as `SSP_API_KEY`. Use the `admin` preset only for
management tools. Add `--expires-in-days` to set an expiration.

## Functions

Build a function from source and run it locally in the SDK sandbox.

```shell
ssp run rerank.py:score --input '[3, 1, 2]'
ssp run bm25.ts:rank --input '[3, 1, 2]'
ssp run ./ranker:Score --input '[3, 1, 2]'
```

A function reference is `path:entry`. Without `:entry`, the function named after the file is used. Python, JavaScript, TypeScript, C, and C++ use a source file. Go uses a module directory and Rust a library crate. The function takes one JSON value and returns one; in C and C++ it takes and returns a NUL-terminated JSON string allocated with `malloc`. `ssp` builds every function into a WebAssembly component itself and rejects prebuilt `.wasm` files.

## Groups

Create a group of named parameters.

```shell
ssp group create atlas-search ranker=rerank.py:score top_k=10 prompt=prompt.md
```

Each `NAME=VALUE` resolves in this order: a function, a `.json` file, any other file as text, then a JSON literal. Anything else is an error. Quote string literals as JSON, such as `model='"claude-sonnet-5-5"'`.

Update a group. Parameters merge, and `NAME=` removes one.

```shell
ssp group update atlas-search top_k=20 prompt=
ssp group list
ssp group show atlas-search
ssp group delete atlas-search
```

An update creates the next group version only when a value changes. Functions are compared by source, so rebuilding unchanged code is not a change. A group in a draft or a running experiment cannot be deleted.

## Experiments

Create a draft that compares groups with control.

```shell
ssp experiment create rank-v2 --group atlas-search=0.2 \
  --assignment user_id --eligibility 'context.country == "US"' \
  --description 'Test sorted search results.'
```

Change the draft. Omitted flags keep their values, and `--group` replaces the groups.

```shell
ssp experiment update rank-v2 --group atlas-search=0.5
ssp experiment update rank-v2 --no-eligibility
```

Publish the draft and run it, stop it, or restart a published version.

```shell
ssp experiment start rank-v2
ssp experiment stop rank-v2
ssp experiment start rank-v2 --version 1
```

Starting pins the newest version of each group and stops the previously running version. An unchanged draft restarts the newest version.

Read experiments and summarize an outcome by group.

```shell
ssp experiment list
ssp experiment show rank-v2
ssp experiment results rank-v2 --outcome click
ssp experiment results rank-v2 --outcome purchase --metric value --version 2
```

Delete an experiment and all of its runs and outcomes.

```shell
ssp experiment delete rank-v2 --yes
```

## PostgreSQL

Create a read-only credential for your account database.

```shell
ssp database credential create --name analyst
ssp database credential list
ssp database credential revoke dbc_123
```

The credential can read `statespace.runs`, `statespace.outcomes`, and
`statespace.logs`. It cannot write data or connect to another account database.
Connect directly over TLS to your workspace hostname, such as `acme.statespace.app`. Use `sslmode=verify-full` to validate the public certificate. The CLI has no SQL query command
and the API has no SQL query endpoint.

Use a PostgreSQL 16 or newer client for the returned URL's `sslrootcert=system`. Older clients must replace that parameter with the path to a trusted public CA bundle. Keep `sslmode=verify-full`.

Query the logs view with your own SQL client and protected connection settings.

```shell
psql -c 'SELECT * FROM statespace.logs LIMIT 20'
```

## Sessions

List or revoke CLI sessions without exposing their secrets.

```shell
ssp token list
ssp token revoke tok_123
ssp token revoke-all --yes
```

`revoke-all` revokes account API keys, CLI sessions, and browser sessions.

## Audit and storage

Read account audit records and the event storage quota.

```shell
ssp audit --limit 50
ssp audit --limit 50 --before 4821
ssp storage
```

Audit reads require `audit:read`. Records include a `source` field identifying
the control or tenant ledger. IDs support pagination across both ledgers; they
do not define time order. Use `occurred_at` to order events by time.

Events have a 64 KiB size limit, a 90-day
retention limit, and a quota of 1 GiB on the free plan and 10 GiB on other plans. Usage warns at 80%; new events
are rejected when the quota is full.

## Subject erasure

Erase the subject's persisted and pending evidence for one experiment.

```shell
ssp experiment erase-subject rank-v2 user-42
```

Erased data can remain in encrypted backups until backup retention expires.
Operators must reapply later erasures after restoring an older snapshot. The
erasure audit record retains the subject identifier as metadata.
