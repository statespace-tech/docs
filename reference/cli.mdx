`ssp` records builds in CI, shows and stops arms, manages tokens, and runs the proxy and the controller. Install it with the [install script](/getting-started/installation).

```shell
ssp <command> [options]
```

## Global options

Every command takes these options.

<ParamField body="--endpoint" type="string" default="https://api.statespace.com">
  The Statespace API URL. Environment variable: `STATESPACE_URL`.
</ParamField>

<ParamField body="--token" type="string">
  A token. Defaults to the session that `ssp login` saved. Environment variable: `SSP_TOKEN`. Proxies and controllers use a token; CI uses none.
</ParamField>

<ParamField body="--json" type="boolean">
  Print one JSON document instead of text.
</ParamField>

## Output and exit codes

Commands print text on standard output. Notes, warnings, and errors go to standard error. A command that fails exits with status 1. With `--json`, the result is one JSON document, and an error is `{"error": "..."}` on standard error.

## login

Sign in with GitHub and save the session. The command opens a browser, and you approve the terminal's code there.

```shell
ssp login
```

<ParamField body="--no-open" type="boolean">
  Print the sign-in URL. Do not open a browser.
</ParamField>

## logout

Sign this terminal out.

```shell
ssp logout
```

<ParamField body="--all" type="boolean">
  Sign out every session of the account, on every machine.
</ParamField>

## whoami

Show the account, the credential in use, its scopes, and storage use.

```shell
ssp whoami
```

## apply

Record the image that this CI job built. On the default branch, the image becomes the app's default build. On an `exp/` branch, it becomes a version of the arm. The [Statespace action](https://github.com/statespace-tech/action) runs this command.

```shell
ssp apply --image ghcr.io/acme/atlas@sha256:4f2a…
```

<ParamField body="--image" type="string" required>
  The image, by tag or digest. `ssp` resolves a tag to its digest with `docker`. Environment variable: `STATESPACE_IMAGE`.
</ParamField>

<ParamField body="--file" type="string" default="statespace.toml">
  The path of `statespace.toml`.
</ParamField>

<ParamField body="--dry-run" type="boolean">
  Check `statespace.toml` and print the plan, but record nothing. It works outside CI. Give an image that is in the registry.
</ParamField>

`apply` proves the build with the job's GitHub OIDC token, so the workflow needs the permission `id-token: write`.

## status

Show what runs, and why.

```shell
ssp status https://github.com/acme/atlas/pull/418
```

<ParamField body="targets" type="string[]">
  Pull request URLs, repository URLs, or paths. See [Targets](#targets). Without a target, `status` shows the arm of the `exp/` branch that you checked out. Else it shows the app of the nearest `statespace.toml`, else the repository you are in, else every app.
</ParamField>

## stop

Stop arms at once. The Statespace App makes their pull requests drafts and comments who stopped them. Their subjects get the default.

```shell
ssp stop https://github.com/acme/atlas/pull/418
```

<ParamField body="targets" type="string[]" required>
  One or more pull request URLs, repository URLs, or paths. See [Targets](#targets).
</ParamField>

The command does not ask for confirmation, so agents can run it. If it cannot change some pull requests, it names them on standard error and exits with status 1. With `--json`, they are under `failed`.

<Note>
  While GitHub is unavailable, a stop is not possible. Proxies keep their last plan.
</Note>

## resume

Mark ready for review the pull requests that a stop made drafts. Each arm runs again while its pull request can merge.

```shell
ssp resume https://github.com/acme/atlas/pull/418
```

<ParamField body="targets" type="string[]" required>
  One or more pull request URLs, repository URLs, or paths. See [Targets](#targets).
</ParamField>

`resume` changes only the drafts that a stop made. A named pull request that a person made a draft is an error; a wider target skips it. Failures work as for `stop`.

## Targets

`status`, `stop`, and `resume` take the same targets.

| Target | Means |
| --- | --- |
| `https://github.com/acme/atlas/pull/418` | That pull request's arm, in every app it runs in |
| `https://github.com/acme/atlas` | Every arm of the repository's apps |
| `.` or `services/search` | The app of the nearest `statespace.toml`; without one, the repository |

## token create

Create a token. `ssp` prints its secret only once.

```shell
ssp token create --name production --preset runtime
```

<ParamField body="--name" type="string" required>
  A name for the token.
</ParamField>

<ParamField body="--preset" type="string">
  The usual scopes for a job: `runtime`, `controller`, `analyst`, or `admin`. See [Presets](#presets).
</ParamField>

<ParamField body="--scope" type="string">
  A scope, for a combination that no preset covers. Repeat for each: `runtime:read`, `events:write`, `arms:report`, `experiments:write`, `query:read`, or `tokens:manage`.
</ParamField>

<ParamField body="--app" type="string">
  Limit what the token reads in SQL to the views of one app. Needs `query:read`. Environment variable: `STATESPACE_APP`.
</ParamField>

<ParamField body="--expires-in-days" type="integer">
  Days until the token expires. Omit it for no expiration.
</ParamField>

A token with `query:read` also has a database URL. Its user is the token's ID, and its password is the token. Connect over TLS to your workspace host, such as `acme.statespace.app`, with `sslmode=verify-full`. A PostgreSQL 16 or newer client reads the URL's `sslrootcert=system`. With an older client, replace that parameter with the path of a trusted CA bundle.

<Warning>
  Keep the output of `ssp token create` out of logs. Statespace cannot show the secret again.
</Warning>

### Presets

| Preset | Scopes | For |
| --- | --- | --- |
| `runtime` | `runtime:read`, `events:write` | `ssp proxy` |
| `controller` | `runtime:read`, `events:write`, `arms:report` | `ssp controller kubernetes` |
| `analyst` | `query:read` | SQL clients |
| `admin` | Every scope, `tokens:manage` included | Agents that run the whole loop |

## token list

List tokens and sign-in sessions, without their secrets.

```shell
ssp token list
```

## token revoke

Revoke a token or a session by its ID, or all of them.

```shell
ssp token revoke tok_123
```

<ParamField body="id" type="string">
  The ID of the token or session. `ssp token list` shows it.
</ParamField>

<ParamField body="--all" type="boolean">
  Revoke every token and session of the account, and end their database sessions. Needs `--yes`.
</ParamField>

<ParamField body="--yes" type="boolean">
  Confirm `--all`. You cannot undo it.
</ParamField>

## proxy

Run the reverse proxy in front of an app. See [Proxy](/reference/proxy) for every flag.

```shell
ssp proxy --app atlas \
  --image ghcr.io/acme/atlas:main
```

## controller kubernetes

Run the arms of an app on Kubernetes. See [Controller](/reference/controller) for every flag.

```shell
ssp controller kubernetes \
  --app atlas --deployment atlas
```

## Not in the CLI

Some actions are in the dashboard and the API only.

| Action | Where |
| --- | --- |
| Change settings | Commit `statespace.toml`, or use **Edit** in the dashboard |
| Erase a subject | **Apps** page, or `DELETE /v1/apps/{app}/subjects/{subject}` |
| Delete an app | **Apps** page, or `DELETE /v1/apps/{app}`. Every arm must be stopped |

An erasure deletes the subject's runs, requests, and the lines that name it, in one app. Erased data can stay in encrypted backups until their retention ends. The audit record of the erasure keeps the subject ID.

<Warning>
  You cannot undo an erasure or a deletion.
</Warning>

## Limits

An event can be 64 KiB at most, and Statespace keeps events for 90 days. The lines that arms print follow the app's shorter `output_retention_days`. Storage is 1 GiB on the free plan and 10 GiB on other plans. `ssp whoami` shows the use. Statespace warns at 80%, and refuses new events when storage is full.
