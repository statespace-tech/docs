---
title: HTTP API
description: Review account, experiment, runtime, and event routes.
---

The CLI uses an account session. SDKs use `STATESPACE_TOKEN`.

## Account routes

```text
GET    /v1/account
GET    /v1/tokens
POST   /v1/tokens
DELETE /v1/tokens/{id}
GET    /v1/database/credentials
POST   /v1/database/credentials
DELETE /v1/database/credentials/{id}
POST   /v1/query
```

## Experiment routes

```text
GET    /v1/experiments
POST   /v1/experiments
GET    /v1/experiments/{name}
PUT    /v1/experiments/{name}
DELETE /v1/experiments/{name}
POST   /v1/experiments/{name}/state
```

`POST /v1/experiments` creates `v1`. `PUT /v1/experiments/{name}` creates the next immutable draft version.

## SDK routes

```text
GET  /v1/runtime/experiments/{name}
POST /v1/events
POST /v1/runs
POST /v1/outcomes
```

The batch endpoint accepts runs before outcomes in one request.

```json
{
  "runs": [],
  "outcomes": []
}
```

Errors use one JSON object and an HTTP error status.

```json
{
  "error": "bad request: treatment weights must leave a positive weight for control"
}
```
