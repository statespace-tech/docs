---
title: Groups and experiments
description: Define groups of parameters and experiments with CLI flags.
---

The CLI defines groups and experiments with arguments. There is no YAML file. SDKs consume running configurations and never modify them.

## Groups

A group is a named set of parameters.

```shell
ssp group create atlas-search ranker=rerank.py:score top_k=10 prompt=prompts/concise.md
```

Each parameter is a function or a JSON value. Each `NAME=VALUE` resolves in this order.

| Value | Result |
| --- | --- |
| `file.py:entry`, `file.js:entry`, `file.ts:entry`, `file.c:entry`, `file.cpp:entry` | A function built from a source file |
| `./module:Entry`, `./crate:entry` | A function built from a Go module or a Rust crate |
| `file.json` | The file's JSON value |
| Any other file | The file's text |
| `20`, `true`, `'"text"'`, `'{"t": 0.2}'` | A JSON literal |

Anything else is an error, so a mistyped file name never becomes a string. Groups are versioned. A new version is created only when a value or a function's source changes.

## Experiments

An experiment assigns eligible subjects to groups by weight. Control receives the remaining weight and the application's defaults.

```shell
ssp experiment create rank-v2 --group atlas-search=0.2 --group atlas-search-bm25=0.2 \
  --assignment user_id --eligibility 'context.country == "US"' \
  --description 'Test sorted search results.'
```

| Flag | Meaning |
| --- | --- |
| `--group NAME=WEIGHT` | A group and its share of eligible subjects, greater than 0. Weights total at most 1 |
| `--eligibility` | A CEL expression over the SDK `context` |
| `--assignment` | A label for the subject identifier, `subject_id` by default |
| `--description` | Up to 500 bytes |

Every parameter must have one type across the groups of an experiment. A function in one group and a number in another is rejected.

## Randomization unit and eligibility

`--assignment` labels the subject identifier. It does not extract a value from context. The application passes the subject ID to `assign`.

```python
group = experiment.assign("u_42", context={"country": "US"})
```

The backend validates CEL when the draft changes. The SDK evaluates the rule with the supplied context. Ineligible subjects receive the defaults and are recorded with `reason = 'ineligible'`.

## Drafts and versions

`create` and `update` change an experiment's draft. The running version does not change.

```shell
ssp experiment update rank-v2 --group atlas-search=0.5
```

`start` publishes the draft as the next immutable version. It pins the newest version of each group and stops the previously running version. An unchanged draft restarts the newest version.

```shell
ssp experiment start rank-v2
ssp experiment show rank-v2
```

Subjects keep their group across versions wherever its weight still covers their bucket. Restart an earlier version to roll back.

```shell
ssp experiment start rank-v2 --version 1
```
