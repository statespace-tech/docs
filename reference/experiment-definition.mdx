`statespace.toml` holds the settings of an app and of each arm. The "Set up Statespace" pull request adds it at the root of the repository. In a repository with more than one app, each app has the file in its folder. Each branch reads its own copy.

```toml statespace.toml
app = "atlas"
share = 0.05
subject = 'request.headers["x-user-id"]'
eligibility = 'request.headers["cf-ipcountry"] == "US"'
max_traffic = 0.2
output_retention_days = 30
```

Check the file and see the plan. This command records nothing:

```shell
ssp apply --dry-run \
  --image ghcr.io/acme/atlas:main
```

## Keys

Arm settings come from each `exp/` branch. App settings come from the default branch, when CI records a default build, so a branch cannot raise its own limit.

<ParamField path="app" type="string" required>
  The app. 1 to 40 lowercase letters, digits, and underscores. The first character is a letter. It is also the name of the app's PostgreSQL schema. The app's first build creates the app and binds it to the repository.
</ParamField>

<ParamField path="share" type="number">
  Arm setting. The arm's share of all the app's subjects: greater than 0 and at most 1, such as `0.05` for 5%. Required on `exp/` branches. The arm's control gets the share of the largest arm on the same base.
</ParamField>

<ParamField path="subject" type="string" default="request.cookies.ssp_sid">
  Arm setting. A CEL expression over [`request`](#request-fields) that gives the subject ID. The default reads the cookie that `ssp proxy` sets for each new visitor. All arms of an experiment use the same rule.
</ParamField>

<ParamField path="eligibility" type="string">
  Arm setting. A CEL expression over [`request`](#request-fields) that is `true` for subjects who may enter. Omit it to let every subject in. All arms of an experiment use the same rule.
</ParamField>

<ParamField path="max_traffic" type="number" default={1}>
  App setting. The share of the app's subjects that experiments may hold, arms and controls together: greater than 0 and at most 1. Arms that do not fit wait, first come, first served. A lower limit stops no arm that runs. The setup pull request writes `max_traffic = 0.2`. Without the key, the limit is 1.
</ParamField>

<ParamField path="output_retention_days" type="integer" default={7}>
  App setting. The days to keep the lines that arms print, 1 to 365.
</ParamField>

Write CEL expressions in single quotes, so TOML takes them as written. A long rule can use a multi-line literal string:

```toml statespace.toml
eligibility = '''
request.headers["cf-ipcountry"] == "US"
  && request.path.startsWith("/search")
'''
```

`ssp apply` rejects a file with an unknown key, a value out of range, or a rule that does not compile. A commit whose rules differ from the other arms of its experiment fails the `Statespace` check.

## Edit from the dashboard

**Edit** in the dashboard changes `statespace.toml` for you. The Statespace App makes the commit, with you as co-author. You need the write role on the repository.

| Setting | Where the commit goes |
| --- | --- |
| An arm's `share` | The arm's `exp/` branch. CI records the commit |
| `max_traffic`, `output_retention_days` | A new pull request to the default branch. The change takes effect when it merges |

## Branches

The branch name gives the experiment and the arm. Other branches are not experiments.

| Branch | Experiment | Arm |
| --- | --- | --- |
| `exp/recent-clicks` | `recent-clicks` | `recent-clicks` |
| `exp/ranking/recent-clicks` | `ranking` | `recent-clicks` |
| `exp/ranking/bm25` | `ranking` | `bm25` |

Names use 1 to 100 letters, numbers, dots, dashes, or underscores. `control` is reserved. An arm runs while its pull request can merge; see [How it works](/getting-started/how-it-works).

## Request fields

`subject` and `eligibility` read the request as `request`.

| Field | Example |
| --- | --- |
| `request.method` | `"GET"` |
| `request.path` | `"/search"` |
| `request.query` | `{"q": "maps"}` |
| `request.headers` | `request.headers["user-agent"]`. Names are lowercase |
| `request.cookies` | `{"ssp_sid": "sid_…"}` |

A header, cookie, or query parameter that is not in the request is `null`. A subject rule must give a string or an integer of 1 to 128 characters. Otherwise, the request gets the default.
