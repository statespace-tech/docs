---
title: statespace.toml and experiments
description: Review the file that names an app and an arm's settings, and how pull requests make experiments run.
---

Experiments come from branches. A branch named `exp/<experiment>/<arm>` is an arm, and `statespace.toml` on the branch gives its settings. No command starts an experiment: an arm runs while GitHub says that its pull request can merge.

## statespace.toml

The file is at the root of the repository. Each branch reads its own copy.

```toml
app = "atlas"
share = 0.05
subject = 'request.headers["x-user-id"]'
eligibility = 'request.headers["cf-ipcountry"] == "US"'
```

| Key | Meaning |
| --- | --- |
| `app` | 1 to 40 lowercase letters, digits, and underscores, starting with a letter. Also the name of the app's PostgreSQL schema. The app's first build creates it and binds it to the repository |
| `share` | The arm's share of all the app's subjects, greater than 0 and at most 1. Required on `exp/` branches |
| `subject` | A CEL expression over `request` that yields the subject ID. Defaults to `request.cookies.ssp_sid` |
| `eligibility` | A CEL expression over `request` that decides who may enter. Omit it to let everyone in |

On the default branch, Statespace reads only `app`. Use single quotes for CEL expressions, so TOML takes them as written. `ssp check` validates the file.

## Branches

| Branch | Experiment | Arm |
| --- | --- | --- |
| `exp/<experiment>` | `<experiment>` | `<experiment>` |
| `exp/<experiment>/<arm>` | `<experiment>` | `<arm>` |

Names use 1 to 100 letters, numbers, dots, dashes, or underscores. `control` is reserved. Other branches are not experiments.

## Builds and versions

CI runs `ssp apply` on each push. It records the commit's image by digest, proven by the job's GitHub OIDC token.

| Branch | Record |
| --- | --- |
| The default branch | A default build. When a proxy runs it, its commit is a base |
| `exp/…` | A version of the arm at that commit, with the commit's `statespace.toml` and its base: the merge base with the default branch |

An experiment's version changes when its arms, their commits, their shares, or the rules change. Subjects keep their arm across versions.

## Controls

Each base commit of an experiment's arms has a control. It runs the default build of that base, and gets the share of the largest arm on that base. An arm's base must have run as the default; until then, the arm waits.

## What runs

| The pull request | The arm |
| --- | --- |
| Can merge (GitHub's merge state is clean, unstable, or has hooks) | Runs the head commit |
| Never could merge | Does not run |
| Could merge, and then could not | Runs the last commit that could merge. The `statespace/arm` check warns after 7 days |
| Is a draft, or a reviewer requested changes | Stops |
| Merged | Ends the experiment. Other arms run again from bases built after the merge |
| Closed | The arm is removed |

The arms of an experiment must use the same `subject` and `eligibility`. A commit with other rules fails `statespace/apply`. The arms of an app fit in its traffic limit, first come, first served.

```shell
ssp app set atlas --max-traffic 0.2
```

## Request rules

`subject` and `eligibility` read the request as `request`.

| Field | Value |
| --- | --- |
| `request.method` | `"GET"` |
| `request.path` | `"/search"` |
| `request.query` | `{"q": "maps"}` |
| `request.headers` | Lowercase names, such as `request.headers["user-agent"]` |
| `request.cookies` | `{"ssp_sid": "sid_…"}` |

A missing header, cookie, or query parameter is `null`. A subject rule must yield a string or an integer of 1 to 128 characters; otherwise the request gets the default.

```shell
ssp check --path /search --query q=maps --header cf-ipcountry=US --cookie ssp_sid=u_1
```
