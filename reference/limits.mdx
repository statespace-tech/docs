This page lists the limits and times of Statespace.

## Retention

<Planned />

| Data | Kept |
| --- | --- |
| The record of each subject of an arm | While the version runs. Statespace deletes it when the version stops |
| The results of a stopped version | Until you remove the app |
| History and results of a `gone` experiment | Kept. `ssp experiment list --all` shows it |

Statespace never keeps data about live or overrides. See [What Statespace keeps](/concepts/data).

## Storage

| Limit | Value |
| --- | --- |
| One account on the free plan | 1 GiB. Statespace warns at 80% |
| One account on another plan | 10 GiB, unless Statespace gives the account its own limit. Statespace warns at 80% |
| One subject of a running version | 256 bytes of the storage of the account |
| Subjects in the memory of one proxy instance, before it sends them | 50,000. Above this, the proxy drops the oldest |

When an account is full, Statespace takes no new subjects. The subjects that it has stay. `GET /v1/storage` gives the use of the account. To erase a subject, use `POST /v1/subjects/erase`. See [API](/reference/api#other).

## Names and values

| Value | Limit |
| --- | --- |
| App name | 1 to 63 characters: lowercase letters, digits, and `-`. Unique in the workspace |
| Experiment name | 1 to 40 characters: lowercase letters, digits, and `-` |
| Event name | 1 to 64 characters: a lowercase letter, then lowercase letters, digits, and `_` |
| Commit prefix | 7 characters or more |
| `--note` | 1 to 200 characters, one line |
| Share of an arm | A fraction, such as `0.05`. `0` removes the arm |
| `max_traffic` | More than 0, at most 1. Default `0.2` |
| Shares of all running experiments of an app | 1 at most |
| Arms to start an experiment | 2 or more |
| Commit status description | 140 characters |

## Times

| Item | Time |
| --- | --- |
| Arms of a starting experiment become ready | 5 minutes at most. Then the start fails |
| Arms of a stopped experiment leave traffic | Seconds |
| Subject cookie `ssp_sid` | 90 days, renewed on each response |
| Override cookie `ssp` | 1 hour, renewed on each request |
| Commit status update | At each change of state, and once an hour while the experiment runs |
| Roles from GitHub | Kept 10 minutes |
| Proxy lease | 30 seconds. The holder renews it every 10 seconds |
| Runtime configuration older than this sends every request to live | 5 minutes |

## File runtimes

| Item | Limit |
| --- | --- |
| Check of each build folder | Every 60 seconds |
| `--cache` | 256 MB for each proxy instance |
| Live files in `--cache` | 10 seconds |
| Arm files in `--cache` | Until the arm stops |
| `files` location of a build | 1024 characters at most |

## Results

| Item | Limit |
| --- | --- |
| 95% intervals of an arm | From 30 subjects. Below, the interval is `[–]` |
| Split check | From 100 subjects in the arms of the experiment. It reports `split off` when the ratio is too far from the shares to come from chance (less than 1 time in 1,000) |
| Proxy sends its data to Statespace | Every 60 seconds, and when it stops |
