The CLI, the dashboard, the action, and the proxy use this API. Agents and scripts can use it too.

```text
https://api.statespace.com
```

## Requests

- Send `Authorization: Bearer <credential>` on each route. See [Credentials](/concepts/permissions#credentials).
- Bodies and responses are JSON.
- An error is `{"error": "..."}` with a status from 400 to 599.
- A commit is the full commit or its first 7 characters or more.

```shell
curl -sS https://api.statespace.com/v1/apps \
  -H "Authorization: Bearer $GITHUB_TOKEN"
```

## CI

### POST /v1/ci/builds

Record a build. The credential is the OIDC token of the GitHub Actions job. The repo and the commit come from the token. `statespace-tech/action` calls this route.

| Body | Type | Means |
| --- | --- | --- |
| `image` | string | The image, by digest |
| `path` | string | The folder of `statespace.toml` |
| `app` | string, optional | The app that the build is for |
| `config` | string | The text of `statespace.toml` |

The response has `repo`, `commit`, `path`, `app`, `image`, and `warnings`, a list.

## Apps

| Route | Body | Response |
| --- | --- | --- |
| `GET /v1/apps` | | `{"apps": [App]}` |
| `POST /v1/apps` | `name`, `repo`, `path`, `note`? | `App` |
| `GET /v1/apps/{app}` | | `AppDetail` |
| `DELETE /v1/apps/{app}` | `note`? | `{"deleted": App}` |

`?` marks an optional key.

## Experiments

| Route | Body | Response |
| --- | --- | --- |
| `GET /v1/apps/{app}/experiments` | | `{"experiments": [Experiment]}` |
| `GET /v1/apps/{app}/experiments/{exp}` | | `ExperimentDetail` |
| `PATCH /v1/apps/{app}/experiments/{exp}/arms` | `arms`, `note`? | `{"experiment": Experiment, "added", "changed", "removed"}` |
| `POST /v1/apps/{app}/experiments/{exp}/start` | `note`? | `Experiment`, in the state `starting` |
| `POST /v1/apps/{app}/experiments/{exp}/stop` | `note`? | `Experiment` |

- `arms` is a map of commit to share, such as `{"a1b2c3d": 0.05, "e5f6a7b": 0}`. A share of `0` removes the arm. Only the commits in the map change.
- After `start`, get the experiment until its state is `running` or `stopped`. The CLI does this.

This example sets two arms of `checkout`:

```shell
app=https://api.statespace.com/v1/apps/shop-prod
curl -sS -X PATCH "$app/experiments/checkout/arms" \
  -H "Authorization: Bearer $GITHUB_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"arms": {"c0ffee1": 0.05, "a1b2c3d": 0.05}}'
```

## Runtime

Only runtime tokens use these routes. The proxy calls them.

### GET /v1/runtime/apps/\{app\}

The runtime configuration of the app.

```json
{
  "app": "shop-prod",
  "salt": "…",
  "settings_hash": "…",
  "settings": {"overrides": false, "redact": []},
  "live": {"commit": "c0ffee1…", "image": "…@sha256:…"},
  "experiments": [
    {
      "name": "checkout",
      "version": 3,
      "state": "running",
      "subject": "…",
      "eligibility": null,
      "events": [
        {"name": "purchase", "source": "request",
         "match": "…"}
      ],
      "arms": [
        {"commit": "a1b2c3d…", "image": "…@sha256:…",
         "ranges": [[0.05, 0.10]]}
      ]
    }
  ],
  "lease": {"holder": "instance-id", "expires_at": "…"},
  "poll_interval_seconds": 5
}
```

- `experiments` holds the `starting` and `running` experiments, in the order of `statespace.toml`.
- The proxy routes only to `running` experiments. The lease holder starts the arms of both.
- Before the first report, `live` is `null`. The proxy then sends all requests to live.

### POST /v1/runtime/apps/\{app\}/report

Each proxy instance reports. Only the lease holder sends `units`.

| Body | Means |
| --- | --- |
| `instance` | The ID of the instance |
| `version` | The version of the proxy |
| `orchestrator` | `docker`, `cloudrun`, or `kubernetes` |
| `live_image` | The image that live runs |
| `settings_hash` | The hash of the settings that the instance uses |
| `units` | `[{"experiment", "commit", "address", "ready", "reason"}]` |

The response is `{"lease": bool, "expires_at"}`.

### POST /v1/events

Send recorded rows. The body has `app`, `runs`, `requests`, `stdout`, `stderr`, `events`, and `lifecycle`. Each row has `id`, `experiment`, `arm`, `version`, and `timestamp`. `arm` is the commit. `id` makes a second send of a row change nothing.

The lifecycle events are `started`, `ready`, `stopped`, and `failed`.

## Objects

### App

| Field | Means |
| --- | --- |
| `name` | The app |
| `repo` | The repo, such as `acme/shop` |
| `path` | The folder of `statespace.toml` |
| `note` | The note |
| `live` | `{"commit", "image", "built_at"}`, or `null` |
| `experiments` | The number of running experiments |
| `created_at` | When the app was added |
| `level` | The level of the caller: `read`, `write`, or `admin` |

### Experiment

| Field | Means |
| --- | --- |
| `name` | The experiment |
| `app` | The app |
| `state` | `stopped`, `starting`, `running`, or `gone` |
| `reason` | One line about the state |
| `version` | The current or last version |
| `definition` | `{"subject", "eligibility", "max_share"}` |
| `arms` | `[Arm]` |
| `reference` | The commit of the reference arm |
| `headline` | `{"label", "values": {"<commit>": number or null}}`, or `null` |
| `started_by`, `started_at` | Who started the current or last version, and when |
| `stopped_at` | When the last version stopped |

### Arm

| Field | Means |
| --- | --- |
| `commit` | The commit, the ID of the arm |
| `share` | The share of the app's subjects |
| `image` | The image of the build |
| `ready` | `true` when the copy of the arm is ready |
| `ahead`, `behind` | Commits ahead of and behind the live commit |
| `live_contains` | `true` when the live commit contains the arm's commit |
| `added_by`, `added_at` | Who added the arm, and when |

### ExperimentDetail

An `Experiment`, with these fields:

| Field | Means |
| --- | --- |
| `source` | `{"commit", "path"}`: where the definition comes from |
| `totals` | `{"<commit>": Totals}` |
| `metrics` | `[{"label", "values"}]` |
| `split` | `{"ok", "p"}`, or `null` |
| `events` | `[{"name", "values"}]`: the top events |
| `versions` | `[{"version", "arms", "started_at", "stopped_at", "stopped_by", "reason"}]` |
| `history` | Starts, stops, and metric changes |
| `drift` | `{"live_commit"}`, or `null` |
| `override_urls` | `{"<commit>": url}`, or `null` |
