---
title: PostgreSQL schema
description: Review account database tables and the logs view.
---

Each account has one isolated PostgreSQL database. The API commits events to an account outbox. The worker writes the final event rows. Direct credentials can read only runs, outcomes, and the logs view.

The account database contains these tables and the stable analysis view.

```text
statespace.experiments
statespace.experiment_versions
statespace.experiment_groups
statespace.functions (S3 metadata only)
statespace.ingestion_outbox
statespace.audit_events
statespace.runs
statespace.outcomes
statespace.logs
```

Wasm bytes stay in S3. PostgreSQL stores their object keys, SHA-256 hashes, and publisher provenance.

## Runs

Each SDK assignment creates one row in `statespace.runs`.

| Column | Type |
| --- | --- |
| `id` | `TEXT` |
| `timestamp` | `TIMESTAMPTZ` |
| `experiment_name` | `TEXT` |
| `experiment_version` | `INTEGER` |
| `assignment_type` | `TEXT` |
| `subject_id` | `TEXT` |
| `group_name` | `TEXT` or `NULL` |
| `assigned` | `BOOLEAN` |
| `reason` | `TEXT` |
| `config` | `JSONB` |
| `context` | `JSONB` |

## Outcomes

A run can have zero or more rows in `statespace.outcomes`.

| Column | Type |
| --- | --- |
| `id` | `TEXT` |
| `run_id` | `TEXT` |
| `name` | `TEXT` |
| `data` | `JSONB` |
| `timestamp` | `TIMESTAMPTZ` |

## Logs view

`statespace.logs` left joins runs to outcomes. It keeps runs that do not yet have an outcome.

Compare assigned groups with a SQL client.

```sql
SELECT
  experiment_version,
  group_name,
  count(*) AS observations,
  avg((data->>'relevance')::double precision) AS mean_relevance
FROM statespace.logs
WHERE experiment_name = 'rank-v2'
  AND assigned
GROUP BY experiment_version, group_name;
```

Create a revocable connection URL for a SQL client.

```shell
ssp database credential create --name analyst
```
