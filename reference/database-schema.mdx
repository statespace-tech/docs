---
title: PostgreSQL schema
description: Review account database tables and the logs view.
---

Each account has one isolated PostgreSQL database. The API commits events to an account outbox. The worker writes the final event rows. Direct credentials can read only runs, outcomes, and the logs view.

The account database contains these tables and the stable analysis view.

```text
statespace.artifacts            uploaded components, addressed by SHA-256
statespace.groups               immutable versions of each group's parameters
statespace.experiments          each experiment's draft
statespace.experiment_versions  published versions
statespace.experiment_groups    the group versions and ranges each version pins
statespace.ingestion_outbox
statespace.audit_events
statespace.runs
statespace.outcomes
statespace.logs
```

Component bytes stay in S3. PostgreSQL stores their object keys, SHA-256 hashes, and publisher provenance.

## Runs

Each SDK assignment creates one row in `statespace.runs`.

| Column | Type |
| --- | --- |
| `id` | `TEXT` |
| `timestamp` | `TIMESTAMPTZ` |
| `experiment_name` | `TEXT` |
| `experiment_version` | `INTEGER` |
| `subject_id` | `TEXT` |
| `group_name` | `TEXT`, or `NULL` when the subject is not assigned |
| `reason` | `assigned`, `ineligible`, or `eligibility-error` |
| `context` | `JSONB` |

## Outcomes

Each logged outcome creates one row in `statespace.outcomes`. Outcomes belong to a subject in an experiment, so any process can log them.

| Column | Type |
| --- | --- |
| `id` | `TEXT` |
| `timestamp` | `TIMESTAMPTZ` |
| `experiment_name` | `TEXT` |
| `subject_id` | `TEXT` |
| `name` | `TEXT` |
| `data` | `JSONB` |

The SDKs record a `statespace.error` outcome when a parameter falls back to the application's default.

## Logs view

`statespace.logs` has one row for each run and outcome it led to. Each outcome joins the latest run of the same subject that started at or before it. Runs without outcomes have `NULL` outcome columns.

| Column | Source |
| --- | --- |
| `run_id`, `run_timestamp`, `experiment_name`, `experiment_version`, `subject_id`, `group_name`, `reason`, `context` | The run |
| `group_version`, `parameters` | The group version the run's experiment version pinned |
| `outcome_id`, `outcome_timestamp`, `outcome_name`, `data` | The outcome |

Compare groups with a SQL client.

```sql
SELECT
  experiment_version,
  group_name,
  count(DISTINCT subject_id) AS subjects,
  avg((data->>'position')::double precision) AS mean_position
FROM statespace.logs
WHERE experiment_name = 'rank-v2'
  AND reason = 'assigned'
  AND outcome_name = 'click'
GROUP BY experiment_version, group_name;
```

Create a revocable connection URL for a SQL client.

```shell
ssp database credential create --name analyst
```
