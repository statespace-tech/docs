---
title: Experiment YAML
description: Review all experiment definition fields.
---

An experiment file contains one logical experiment and one or more treatment groups.

```yaml
name: rank-v2
description: Test reciprocal rank fusion.
assignment: user_id
eligibility: 'context.country == "US" && context.plan == "pro"'
groups:
  - name: treatment
    weight: 0.2
    config:
      reranker: rrf
  - name: treatment-large
    weight: 0.1
    config:
      reranker: rrf
      candidates: 100
```

## Fields

| Field | Required | Meaning |
| --- | --- | --- |
| `name` | Yes | Stable experiment name. |
| `description` | No | Short statement of the tested change. |
| `assignment` | No | Identifier type, such as `user_id`. The default is `subject_id`. |
| `eligibility` | No | CEL expression over the SDK `context` object. |
| `groups` | Yes | One or more treatment groups. |
| `groups[].name` | Yes | Unique treatment name. `control` is reserved. |
| `groups[].weight` | Yes | Assignment probability greater than `0` and less than `1`. |
| `groups[].config` | No | JSON object returned to assigned subjects. |

Treatment weights must total less than `1.0`. Statespace adds implicit control with the remaining weight and `{}` configuration.

```text
control weight = 1 - sum(treatment weights)
```

The CLI validates YAML and CEL before it creates a version.

```shell
ssp experiment create --file experiment.yaml
ssp experiment publish --file experiment.yaml
```
