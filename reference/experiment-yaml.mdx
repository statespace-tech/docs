An experiment definition contains its identity, assignment design, traffic, and groups. `statespace.load()` validates the same schema used by the public `Experiment` and `Group` models.

## Identity fields

<ParamField body="name" type="string" required>
  Set a unique experiment name within the account database.
</ParamField>

<ParamField body="description" type="string" required>
  State the change tested by the experiment.
</ParamField>

## Assignment field

<ParamField body="assignment" type="string | object" required>
  Set the stable randomization unit or configure stratified assignment.
</ParamField>

A string selects simple random assignment.

```yaml
assignment: user_id
```

An object configures the complete assignment method.

```yaml
assignment:
  unit: user_id
  method: stratified
  strata:
    - country
  block_size: 10
```

| Field | Type | Default |
| --- | --- | --- |
| `assignment.unit` | `string` | Required |
| `assignment.method` | `random \| stratified` | `random` |
| `assignment.strata` | `string[]` | `[]` |
| `assignment.block_size` | positive integer | `4` |

## Sampling fields

<ParamField body="traffic" type="number" default="1.0">
  Set the stable sampling probability from greater than `0.0` through `1.0`.
</ParamField>

<ParamField body="layer" type="string">
  Reference an exclusion layer for experiments that must not overlap.
</ParamField>

## Group fields

<ParamField body="groups" type="array" required>
  Define one or more named treatment groups.
</ParamField>

<ParamField body="groups[].name" type="string" required>
  Set a unique group name.
</ParamField>

<ParamField body="groups[].weight" type="number">
  Set a positive assignment probability.
</ParamField>

<ParamField body="groups[].config" type="object" default="{}">
  Define the JSON-compatible runtime configuration.
</ParamField>

If `control` is absent, the SDK adds it with the remaining weight and an empty configuration. If all weights are absent, the SDK divides assignment equally across the explicit groups and control.

## Complete definition

This definition uses stratified assignment, limited traffic, and one treatment.

```yaml
name: rank-v2
description: Test reciprocal rank fusion.
assignment:
  unit: user_id
  method: stratified
  strata:
    - country
  block_size: 10
traffic: 0.1
layer: search-ranking
groups:
  - name: treatment
    weight: 0.2
    config:
      reranker: rrf
```

Validate the file in application code.

```python
import statespace

experiment = statespace.load("experiment.yaml")
```

<Note>
  `statespace.init(**experiment)` creates and starts an absent experiment. It rejects a conflicting registered definition with the same name.
</Note>
