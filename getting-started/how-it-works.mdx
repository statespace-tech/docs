This page answers two questions: where does a request go, and who decides that an arm may run?

## What serves a request

`ssp proxy` sends every request to one of three places.

| Target | What it runs | Who gets it |
| --- | --- | --- |
| Default | The image you deployed | Every subject outside an experiment |
| Control | The default build of the commit where an arm's branch started | An experiment's baseline |
| Arm | The image of a commit of an `exp/` branch | An experiment's treatment |

A control gets the share of the largest arm on its base. Compare each arm with its control, not with the default. The arm and its control differ only by the change of the branch.

## What decides

GitHub decides what may run. Statespace decides only whether it runs fairly.

<WhatRuns />

A stop from Statespace makes the pull request a draft, so GitHub stays the one record of what may run. Each new commit needs a new approval, unless your repository says otherwise.

## Parts of Statespace

| Part | What it does |
| --- | --- |
| GitHub App | Opens the setup pull request. Reads the state of pull requests. Posts the `statespace/apply` and `statespace/arm` checks. Makes pull requests drafts when you stop arms |
| Dashboard | Shows what runs, stops and resumes arms, and edits `statespace.toml` through the App |
| `ssp status`, `stop`, `resume` | Show and stop arms from a terminal or an agent, by pull request URL, repository URL, or path |
| `ssp apply` | Runs in CI, and records the image of each commit with the job's GitHub OIDC token |
| `ssp proxy` | Assigns each request's subject and forwards the request. With `--image`, it also runs the default and the arms on Docker |
| `ssp controller kubernetes` | Runs the arms on Kubernetes as copies of the default's Deployment |
| PostgreSQL | Keeps one isolated database for each account, with one schema of views for each app |

## What Statespace records

Your app prints what happens, as it does now. Statespace records every line that an arm prints. A JSON line with a `subject` field belongs to that subject's arm.

```python app.py
print(json.dumps({
    "event": "click",
    "subject": subject,
    "position": 1,
}))
```

Statespace never records the default.
