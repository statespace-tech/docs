title: Installation
description: Install the CLI and a runtime SDK.
---

## CLI

Install `ssp` on macOS or Linux.

```shell
curl -fsSL https://statespace.com/install | bash
```

Confirm the installation.

```shell
ssp --version
```

## SDKs

Install the SDK for the application language.

<CodeGroup>
```shell Python
pip install statespace-sdk
```

```shell TypeScript
npm install @statespace-tech/sdk
```

```shell Go
go get github.com/statespace-tech/go-sdk
```
</CodeGroup>

Create an application token with the CLI, then store it in a secret manager.

```shell
ssp token create --name production
export STATESPACE_TOKEN=ssp_token_7j...
```

Use `STATESPACE_URL` only when the application connects to a self-hosted or local API.

```shell
export STATESPACE_URL=http://127.0.0.1:8080
```
