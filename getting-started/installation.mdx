Set up Statespace for your GitHub account, your terminal, and your coding agents.

## GitHub App

On [statespace.com](https://statespace.com), select **Connect GitHub**. Install the Statespace GitHub App on the account that owns your repos. The same screen signs you in.

The App asks for these permissions. It never writes code.

| Permission | Access | Why |
| --- | --- | --- |
| Contents | Read | Find the commits ahead of and behind live |
| Metadata | Read | Required by GitHub |
| Members | Read | Find the role of each person on a repo |
| Commit statuses | Read and write | Post the `statespace/<app>/<experiment>` status on each arm's commit |

Permissions in Statespace come from GitHub. See [Permissions](/concepts/permissions).

## CLI

Install the CLI on macOS or Linux.

```shell
curl -fsSL https://statespace.com/install.sh | bash
```

Sign in with GitHub. The CLI shows a code. Approve the code in the browser.

```shell
ssp login
```

Make sure that the CLI uses the correct account.

```shell
ssp --version
ssp whoami
```

To use an API other than `https://api.statespace.com`, set `STATESPACE_API`.

```shell
export STATESPACE_API=http://127.0.0.1:8080
```

## Proxy image

On Cloud Run and Kubernetes, the proxy runs from the image `ghcr.io/statespace-tech/statespace`. On a machine with Docker, the proxy is the same `ssp` binary.

## Coding agents

Give this prompt to your coding agent. The skill tells the agent how to install the CLI, write `statespace.toml`, run experiments, and read the evidence.

```text
Read https://statespace.com/skill.md and follow it.
```

See [Agents](/guides/agents) for the workflow.
