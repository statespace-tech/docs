---
title: Installation
description: Install the CLI and a runtime SDK.
---

## CLI

Install the current `ssp` checkout on macOS or Linux. Run from the parent workspace.

```shell
cargo install --path cli --locked
```

Confirm the installation.

```shell
ssp --version
```

## SDKs

Install the SDK for the application language.

<CodeGroup>
```shell Python
pip install statespace-sdk
```

```shell TypeScript
npm install @statespace-tech/sdk
```

```shell Go
go get github.com/statespace-tech/go-sdk
```
</CodeGroup>

Create a runtime API key with the CLI, then store the returned secret as `SSP_API_KEY` in a secret manager.

```shell
ssp key create --name production --preset runtime
```

Set `STATESPACE_URL` when the CLI or application uses a local API or a hosted domain other than its default.

```shell
export STATESPACE_URL=http://127.0.0.1:8080
```
