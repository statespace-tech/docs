## CLI

Install the CLI on macOS or Linux. The installer downloads a prebuilt binary and verifies its SHA-256 checksum. Rust and Cargo are not required.

```shell
curl -fsSL https://statespace.com/install.sh | bash
```

The installer installs the latest release, the only one published.

Confirm the installation.

```shell
ssp --version
```

The same binary runs `ssp host` on your servers. Install it in the image or machine that runs your app.

## Keys

Each place that uses Statespace needs its own key.

| Where | Key | Purpose |
| --- | --- | --- |
| Your terminal | `ssp login` | Manage apps, variants, and experiments |
| CI | `ssp key create --scope experiments:write` and `SSP_SIGNING_KEY` | Publish signed variants |
| Your servers | `ssp key create --preset runtime` | Run `ssp host` |

Create a runtime key for `ssp host`, then store the returned secret as `SSP_API_KEY` in a secret manager.

```shell
ssp key create --name production --preset runtime
```

Create a signing key pair once. Keep the private key in CI. Give the public key to `ssp host --trust-key`.

```shell
ssp variant keygen
```

Set `STATESPACE_URL` when the CLI or host uses a local API or a hosted domain other than its default.

```shell
export STATESPACE_URL=http://127.0.0.1:8080
```

See [Deployment](/getting-started/deployment) to publish variants from CI and run hosts in production.
