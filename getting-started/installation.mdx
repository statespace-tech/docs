## CLI

Install the CLI on macOS or Linux. The installer downloads a prebuilt binary and verifies its SHA-256 checksum. Rust and Cargo are not required.

```shell
curl -fsSL https://statespace.com/install | bash
```

Building functions from source downloads each language's pinned tools on first use. Go, Rust, and JavaScript builds also need the Go toolchain, Rust with `rustup`, or Node.js.

Confirm the installation.

```shell
ssp --version
```

## SDKs

Install the SDK for the application language.

<CodeGroup>
```shell Python
pip install "git+https://github.com/statespace-tech/python-sdk.git@v0.1.1"
```

```shell TypeScript
npm install "github:statespace-tech/typescript-sdk#v0.1.1"
```

```shell Go
go get github.com/statespace-tech/go-sdk@v0.1.1
```
</CodeGroup>

Create a runtime API key with the CLI, then store the returned secret as `SSP_API_KEY` in a secret manager.

```shell
ssp key create --name production --preset runtime
```

Set `STATESPACE_URL` when the CLI or application uses a local API or a hosted domain other than its default.

```shell
export STATESPACE_URL=http://127.0.0.1:8080
```
