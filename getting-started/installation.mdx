## CLI

Install the CLI on macOS or Linux. The installer downloads a prebuilt binary and verifies its SHA-256 checksum. Rust and Cargo are not required.

```shell
curl -fsSL https://statespace.com/install.sh | bash
```

The installer installs the latest release, the only one published.

Confirm the installation.

```shell
ssp --version
```

The same binary runs `ssp proxy` on machines with Docker. On Kubernetes, the proxy and the controller run from the `ghcr.io/statespace-tech/ssp` image.

## Tokens

Each place that uses Statespace needs its own token.

| Where | Token | Purpose |
| --- | --- | --- |
| Your terminal | `ssp login` | Manage apps, variants, experiments, and tokens |
| CI | `--preset publisher`, and `SSP_SIGNING_KEY` | Publish signed variants |
| Your servers | `--preset runtime` | Run `ssp proxy` |
| Kubernetes | `--preset controller` | Run `ssp controller` |
| SQL clients | `--preset analyst` | Read runs, lines, and requests |

Create a runtime token for `ssp proxy`, then store the returned token as `SSP_TOKEN` in a secret manager.

```shell
ssp token create --name production --preset runtime
```

Create a signing key pair once. Keep the private key in CI. Give the public key to `ssp proxy --trust-key` and `ssp controller --trust-key`.

```shell
ssp keygen
```

Check which credential the CLI uses and what it may do.

```shell
ssp whoami
```

Set `STATESPACE_URL` when the CLI or proxy uses a local API or a hosted domain other than its default.

```shell
export STATESPACE_URL=http://127.0.0.1:8080
```

See [Deployment](/getting-started/deployment) to publish variants from CI and run proxies in production.
