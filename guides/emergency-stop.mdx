---
title: Stop in an emergency
sidebarTitle: Emergency stop
description: Take one arm or every arm of an app out of traffic in seconds, from the CLI, the dashboard, or the API.
---

When an arm causes a problem, stop it. Its visitors go back to live in seconds. Then find the cause.

You need the role write or triage on the app's repo. Stop never asks for confirmation.

## Stop one arm

```shell
ssp arm stop a1b2c3d --app shop-prod \
  --note "checkout errors > 2%"
```

## Stop every arm of an app

A hold on the app covers every arm, also the arms that people add later.

```shell
ssp app stop shop-prod --note "incident 214"
```

## Stop from the dashboard

1. Open the app on the **Apps** page.
2. Select **Stop** on the app, or on one arm.

## Stop through the API

Use the API when the CLI is not available, such as from an alert script. Send a GitHub token of a person with the write role on the repo.

```shell
curl -sS -X POST \
  https://api.statespace.com/v1/apps/shop-prod/stop \
  -H "Authorization: Bearer $GITHUB_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"note": "alert: checkout errors > 2%"}'
```

To stop one arm, use the arm's route.

```shell
curl -sS -X POST \
  https://api.statespace.com/v1/apps/shop-prod/arms/a1b2c3d/stop \
  -H "Authorization: Bearer $GITHUB_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"note": "checkout errors > 2%"}'
```

The response is the hold. A stop on a target that has a hold returns that hold, and changes nothing.

## Check the stop

```shell
ssp app show shop-prod
```

The output shows the hold. The commit status of each stopped arm is `failure`, for example:

```text
Stopped by maria with ssp app stop · incident 214
```

## Resume

Resume clears only the hold that it names.

```shell
ssp app resume shop-prod
ssp arm resume a1b2c3d --app shop-prod \
  --note "fixed in b2c3d4e"
```

When an arm has a hold of its own, `ssp app resume` keeps that hold, and says so. Resume never brings back a removed arm.

<Tip>
  To run a fix, push it, and add its commit as a new arm. Then remove the old arm.
</Tip>
