---
title: Stop in an emergency
sidebarTitle: Emergency stop
description: Take the arms of one or more experiments out of traffic in seconds, from the CLI, the dashboard, or the API.
---

When an experiment causes a problem, stop it. The visitors of its arms go back to live in seconds. Then find the cause.

You need the role Write or Maintain on the app's repo. Stop never asks for confirmation.

## Stop one experiment

```shell
ssp experiment stop checkout --app shop-prod \
  --note "checkout errors > 2%"
```

A stop on a stopped experiment returns it unchanged.

## Stop every experiment of an app

There is no stop for a whole app. Stop each running experiment by name.

1. List the running experiments.

   ```shell
   ssp experiment list --app shop-prod --running
   ```

2. Stop them with one command. `stop` takes one or more names.

   ```shell
   ssp experiment stop checkout us-landing \
     --app shop-prod --note "incident 214"
   ```

## Stop from the dashboard

1. Open the app on the **Apps** page.
2. Open the experiment.
3. Select **Stop**, and write a note.

## Stop through the API

Use the API when the CLI is not available, such as from an alert script. Send a GitHub token of a person with the role Write or Maintain on the repo.

```shell
app=https://api.statespace.com/v1/apps/shop-prod
curl -sS -X POST "$app/experiments/checkout/stop" \
  -H "Authorization: Bearer $GITHUB_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"note": "alert: checkout errors > 2%"}'
```

The response is the `Experiment`, in the state `stopped`.

## Check the stop

```shell
ssp experiment show checkout --app shop-prod
```

The output shows the state `stopped`, who stopped it, and the note. The commit status of each arm becomes `success`, for example:

```text
v1 stopped · 2,040 subjects
· purchase rate % 3.4 vs 2.8 (c0ffee1)
```

## Run a fix

Each start is a new version. So the evidence of the fix does not mix with the evidence of the stopped version.

1. Push the fix. CI builds and records it.
2. Replace the arm with the fix. `=0` removes the old arm.

   ```shell
   ssp experiment update checkout --app shop-prod \
     --arm a1b2c3d=0 --arm b2c3d4e=0.05
   ```

3. Start the experiment again.

   ```shell
   ssp experiment start checkout --app shop-prod \
     --note "fixed in b2c3d4e"
   ```
