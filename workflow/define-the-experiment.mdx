---
title: Define the experiment
description: Write one testable treatment and eligibility rule.
---

Start with one decision. Choose the subject identifier, eligible population, treatment configurations, and outcome before you start.

## Choose the assignment type

Use an identifier that remains stable for the full experiment.

```yaml
assignment: user_id
```

Use `account_id` when people in one account can affect each other. Use `session_id` when each session can receive an independent treatment.

## Define eligibility

Write a CEL expression that uses only pre-treatment context.

```yaml
eligibility: 'context.country == "US" && context.plan == "pro"'
```

An ineligible subject receives the application default and is recorded as unassigned.

## Define treatments

Put only changed values in each treatment configuration.

```yaml
groups:
  - name: treatment
    weight: 0.2
    config:
      reranker: rrf
```

Control is implicit. The application uses its existing defaults when the SDK returns `{}`.

## Create the draft

Save the complete definition and create `v1`.

```shell
ssp experiment create --file experiment.yaml
```

Review the draft before you start it.

```shell
ssp experiment show --name rank-v2
```
