---
title: Analyze the outcomes
description: Query runs and JSON outcomes in PostgreSQL.
---

Start with allocation and delivery checks. Then estimate the outcome for each group within one experiment version.

Analysis runs against your own PostgreSQL database. Create a read-only credential once and
point any SQL client at it.

```shell
ssp database credential create --name analyst
```

## Check assignment counts

Count assigned and unassigned runs.

```sql
SELECT assigned, reason, count(*)
FROM statespace.runs
WHERE experiment_name = 'rank-v2'
GROUP BY assigned, reason;
```

## Compare groups

Extract numeric values from the JSONB `data` column.

```sql
SELECT
  group_name,
  count(*) AS observations,
  avg((data->>'relevance')::double precision) AS mean_relevance,
  stddev_samp((data->>'relevance')::double precision) AS sd_relevance
FROM statespace.logs
WHERE experiment_name = 'rank-v2'
  AND experiment_version = 1
  AND assigned
  AND outcome_name = 'result'
GROUP BY group_name;
```

For JSON output, use `psql` directly.

```shell
psql "$STATESPACE_DATABASE_URL" -At -c \
  "SELECT json_agg(t) FROM (
     SELECT group_name, count(*) FROM statespace.logs
     WHERE experiment_name = 'rank-v2' GROUP BY group_name
   ) AS t"
```

## Connect another tool

Create a read-only PostgreSQL credential for a BI tool, notebook, or coding agent.

```shell
ssp database credential create --name analyst
```

Revoke the credential when the integration no longer needs access.

```shell
ssp database credential revoke --id dbc_123
```
