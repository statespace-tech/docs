---
title: Apply the treatments
description: Initialize the experiment, assign subjects, and record outcomes.
---

The SDK creates an absent experiment from its definition. It then assigns each subject and records the resulting JSON outcome.

```text
load → initialize → assign → apply → log → flush
```

## Configure the token

Use a read-write token in the application runtime.

```bash
export STATESPACE_TOKEN=ssp_rw_7j...
```

The token identifies the account database. The SDK does not need a separate database name.

## Load the definition

Load and validate the YAML file before initialization.

```python
import statespace

definition = statespace.load("experiment.yaml")
```

You can also build a definition with the public Pydantic models.

```python
experiment = statespace.Experiment(
    name="rank-v2",
    description="Test reciprocal rank fusion.",
    assignment="user_id",
    groups=[
        statespace.Group(
            name="treatment",
            weight=0.2,
            config={"reranker": "rrf"},
        )
    ],
)
```

## Initialize the experiment

Pass the loaded definition to `init`.

```python
with statespace.init(**definition) as run:
    ...
```

Pass a code-defined `Experiment` directly.

```python
with statespace.init(experiment) as run:
    ...
```

The first call creates and starts the experiment. Later calls accept the same definition and reject a conflict with the same name.

## Assign each subject

Request the configuration before you apply the tested behavior.

```python
config = run.get_config("u_42")
reranker = config.get("reranker", None)
```

Repeated calls with the same subject use the same group. Stratified experiments pass declared pre-treatment values through `context`.

## Record each outcome

Record one arbitrary JSON dictionary after the tested behavior runs.

```python
result = search("query goes here", reranker=reranker)
run.log({"relevance": result.relevance, "latency_ms": result.latency_ms})
```

Structured outcomes can include complete conversations or nested application data.

```python
run.log({"messages": messages, "termination": "completed"})
```

## Flush pending records

The context manager flushes and closes the run. Use the explicit lifecycle when a framework controls shutdown.

```python
run = statespace.init(**definition)
try:
    config = run.get_config("u_42")
    run.log({"relevance": 0.7})
    run.flush()
finally:
    run.close()
```
