---
title: Apply the treatments
description: Start an experiment and use its configuration safely.
---

Start the draft only after the application can use every treatment configuration.

```shell
ssp experiment start --name rank-v2
```

## Assign subjects

Pass the stable subject ID and the JSON context used by eligibility.

```python
import statespace

run = statespace.init("rank-v2")
config = run.get_config("u_42", context={"country": "US", "plan": "pro"})
```

Read treatment values with explicit application defaults.

```python
reranker = config.get("reranker", default_reranker)
```

## Record outcomes

Record JSON objects on the run whose configuration could affect the result.

```python
run.log({"relevance": 0.7, "latency_ms": 42})
```

One run can have multiple named outcomes.

```python
run.log({"clicked": True}, name="engagement")
run.log({"latency_ms": 42}, name="performance")
```

## Publish a change

Edit the YAML and publish the next immutable draft version.

```shell
ssp experiment publish --file experiment.yaml
ssp experiment start --name rank-v2 --version 2
```

Starting `v2` stops new assignments to `v1`. Existing `v1` data remains unchanged.
