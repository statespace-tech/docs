---
title: Apply the treatments
description: Assign units, apply configurations, and record observable responses.
---

The SDK converts an experiment definition into one stable runtime decision. The application must apply that decision before it records an exposure.

```text
connect → assign → apply → expose → record → flush
```

## Connect the SDK

Connect with a read-write token scoped to the project.

```python
from statespace import Experiment

experiment = Experiment.connect(
    "atlas-search/rank-v2",
    token="ssp_rw_7j...",
)
```

The SDK downloads the signed experiment manifest and starts background refresh.

## Load the experiment

The SDK caches the manifest for local evaluation. It polls for a new active revision at a bounded interval.

| Condition | SDK behavior |
| --- | --- |
| Cached manifest is current | Evaluate without a network request. |
| Refresh succeeds | Use the new revision for later assignments. |
| Refresh fails | Keep the last valid manifest and report the error. |
| No valid manifest exists | Fail closed and return an SDK error. |

## Assign the unit

Pass one value of the project randomization unit.

```python
run = experiment.run("user_42")
```

The returned run contains `id`, `assignment`, `group`, `config`, `enrolled`, and `revision`.

<Note>
  Repeated calls with `user_42` use the same sampling and group decisions for one revision.
</Note>

## Apply the configuration

Read each parameter with the application default. The default implements the implicit control.

```python
reranker = run.config.get("reranker", None)
result = search("query goes here", reranker=reranker)
```

If `run.enrolled` is false, apply the default behavior and do not attribute an experiment outcome.

## Record the exposure

Create a run only where the application can apply the assigned configuration. This keeps assignment and exposure distinct.

<Warning>
  Do not call `experiment.run()` during prefetch when the user might never receive the behavior. Early exposure logging can dilute the measured effect.
</Warning>

## Record the outcomes

Record one or more responses on the run that caused them.

```python
run.outcome("relevance", value=result.relevance)
run.outcome("latency_ms", value=result.latency_ms)
```

Use structured data when a scalar cannot preserve the evidence.

```python
run.outcome(
    "conversation",
    data={"messages": messages, "termination": "completed"},
)
```

## Flush the events

Flush pending events at a durable application boundary.

```python
experiment.flush(timeout=10.0)
experiment.close(timeout=10.0)
```

The SDK batches retries and uses idempotent event identifiers. The application must handle a final delivery error.
