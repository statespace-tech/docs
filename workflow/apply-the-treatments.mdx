---
title: Apply the treatments
description: Run the app and its variants behind ssp host, and record outcomes.
---

Start the draft once the outcome is deployed and the variant is published.

```shell
ssp experiment start rank-v2 --note 'First run at 20% of US traffic.'
```

Starting publishes the draft as version 1, pins the newest version of each variant, and takes a slice of the app's traffic.

## Run the host

Replace the app's start command with `ssp host`. Give it a runtime key as `SSP_API_KEY` and the public signing key.

```shell
ssp host --app atlas --command "gunicorn -b 127.0.0.1:{port} atlas:app" \
  --health /health --trust-key "$SSP_PUBLIC_KEY"
```

The host runs control from its working directory. It downloads each running variant, checks its signature, unpacks it, and runs it with the same command on its own port. A process gets traffic once `--health` answers 200.

## Keep variants apart from shared state

Variants share the database, cache, and queues with control. Give variants their own environment with `--variant-env`.

```shell
ssp host --app atlas --command "gunicorn -b 127.0.0.1:{port} atlas:app" --trust-key "$SSP_PUBLIC_KEY" \
  --variant-env DATABASE_URL="$VARIANT_DATABASE_URL" \
  --variant-env SCHEDULER_ENABLED=false \
  --variant-env CACHE_PREFIX=variant
```

Use a database user without schema permissions for variants. Land migrations in the deployed code first.

## Record outcomes

Every process can print outcomes. The host reads them from standard output, adds the variant, and sends them.

```python
print(json.dumps({"statespace": "click", "subject": subject, "position": 3}))
```

The host passes every line through to its own output, so existing log collection keeps working. Outcome lines need no `--capture`.

## Check the variants

Check that each host runs the variant before you wait for outcomes.

```shell
ssp app hosts atlas
ssp variant logs atlas-search --app atlas
```

Hosts send lifecycle events, CPU and memory, and per-minute HTTP summaries for every process. Send standard output, standard error, or one row per request too with `--capture`. `--redact` removes matches before lines leave the machine.

```shell
ssp host ... --capture stderr --capture http --redact 'sk_live_\w+'
```

## Publish a change

Publish a new version of the variant, then start the experiment again.

```shell
ssp variant create atlas-search . --app atlas
ssp experiment start rank-v2 --note 'Fix the empty-query crash.'
```

A new variant version does not change the running version until the experiment starts again. Starting version 2 stops assignments to version 1. Existing evidence keeps its original version.
