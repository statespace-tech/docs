title: Analysis walkthrough
description: Check delivery and compare one JSON outcome.
---

Analyze one immutable version at a time.

## Check delivery

Confirm that the SDK recorded assigned and unassigned runs.

```sql
SELECT assigned, reason, count(*)
FROM statespace.runs
WHERE experiment_name = 'rank-v2'
  AND experiment_version = 1
GROUP BY assigned, reason;
```

## Check allocation

Compare observed group shares with configured weights.

```sql
SELECT
  group_name,
  count(*) AS runs,
  count(*)::double precision / sum(count(*)) OVER () AS observed_share
FROM statespace.runs
WHERE experiment_name = 'rank-v2'
  AND experiment_version = 1
  AND assigned
GROUP BY group_name;
```

## Compare the outcome

Read the planned field from each JSON outcome.

```sql
SELECT
  group_name,
  count(*) AS observations,
  avg((data->>'relevance')::double precision) AS mean_relevance,
  stddev_samp((data->>'relevance')::double precision) AS sd_relevance
FROM statespace.logs
WHERE experiment_name = 'rank-v2'
  AND experiment_version = 1
  AND outcome_name = 'result'
GROUP BY group_name;
```

## Preserve the decision

Keep the experiment version, query, result, and decision together in the system that tracks production changes.

```yaml
experiment: rank-v2
version: 1
decision: keep-control
reason: Treatment did not improve the primary relevance outcome.
```
