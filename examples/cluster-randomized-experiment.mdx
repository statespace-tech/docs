---
title: Account-level experiment
description: Keep all users in one account in the same group.
---

Use `account_id` when users in one account share data or can affect each other.

```yaml
name: rank-v2
description: Test reciprocal rank fusion by account.
assignment: account_id
groups:
  - name: treatment
    weight: 0.2
    config:
      reranker: rrf
```

Pass the account ID as the stable subject ID.

```python
run = statespace.init("rank-v2")
config = run.get_config(account.id, context={"country": account.country})
```

Every service instance uses the same experiment salt and hash algorithm. The same account therefore receives the same group on every instance.

```text
account_42 → rank-v2 v1 → control or one treatment
```

Analyze the number of independent accounts instead of the number of requests.

```sql
SELECT group_name, count(DISTINCT subject_id) AS accounts
FROM statespace.runs
WHERE experiment_name = 'rank-v2' AND experiment_version = 1
GROUP BY group_name;
```
