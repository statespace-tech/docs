---
title: Simple A/B experiment
description: Compare a published function with implicit control.
---

This example assigns 20% of eligible US users to `atlas-search@1`. The candidate sorts results. Control preserves the input order.

Publish the candidate before creating the experiment.

```shell
ssp function build rerank.py --language python --entry rerank:rerank --output rerank.wasm
ssp function publish rerank.wasm --name atlas-search
ssp experiment create --name rank-v2 --assignment user_id   --description 'Test sorted search results.'   --eligibility 'context.country == "US"' --variant atlas-search@1=0.2
ssp experiment start --name rank-v2 --version 1
```

See [Define the experiment](/workflow/define-the-experiment) for the `rerank.py` source. Wasm bytes stay in S3 and execute in the SDK's local runtime.

Execute the assigned function and record the same outcome for both groups.

```python
import statespace

with statespace.init("rank-v2") as run:
    rank = run.get_function(
        "u_42", context={"country": "US"}, default=lambda items: items,
    )
    result = rank([3, 1, 2])
    run.log("u_42", {"relevance": 0.7, "result": result})
```

Compare assigned control and candidate within version 1.

```sql
SELECT group_name, count(*) AS observations,
       avg((data->>'relevance')::double precision) AS mean_relevance
FROM statespace.logs
WHERE experiment_name = 'rank-v2' AND experiment_version = 1
  AND assigned AND outcome_name = 'result'
GROUP BY group_name;
```

Candidate rows use group name `atlas-search@1`; control rows use `control`. Check delivery and missing outcomes before interpreting this comparison.
