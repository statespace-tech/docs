---
title: Simple A/B experiment
description: Test one treatment against implicit control.
---

This example changes the ranking algorithm for 20% of eligible subjects.

```yaml
name: rank-v2
description: Test reciprocal rank fusion.
assignment: user_id
eligibility: 'context.country == "US"'
groups:
  - name: treatment
    weight: 0.2
    config:
      reranker: rrf
```

Create and start the experiment.

```shell
ssp experiment create --file experiment.yaml
ssp experiment start --name rank-v2
```

Use the assigned configuration and record relevance.

```python
with statespace.init("rank-v2") as run:
    config = run.get_config("u_42", context={"country": "US"})
    result = search(reranker=config.get("reranker", "current"))
    run.log({"relevance": result.relevance})
```

Compare control and treatment within the same version.

```sql
SELECT
  group_name,
  count(*) AS observations,
  avg((data->>'relevance')::double precision) AS mean_relevance
FROM statespace.logs
WHERE experiment_name = 'rank-v2'
  AND experiment_version = 1
  AND outcome_name = 'result'
GROUP BY group_name;
```
