---
title: Simple A/B experiment
description: Compare one group with implicit control.
---

This example assigns 20% of eligible US users to the group `atlas-search`. Its ranker sorts results. Control preserves the input order.

Create the group and the experiment, then start it.

```shell
ssp group create atlas-search ranker=rerank.py:score
ssp experiment create rank-v2 --assignment user_id --group atlas-search=0.2 \
  --description 'Test sorted search results.' --eligibility 'context.country == "US"'
ssp experiment start rank-v2
```

See [Define the experiment](/workflow/define-the-experiment) for the `rerank.py` source. The function runs in the SDK's local sandbox.

Read the ranker and record the same outcome for every group.

```python
import statespace

experiment = statespace.experiment("rank-v2")
group = experiment.assign("u_42", context={"country": "US"})
result = group.function("ranker", lambda items: items)([3, 1, 2])
experiment.log("u_42", "relevance", {"score": 0.7})
```

Compare the groups.

```shell
ssp experiment results rank-v2 --outcome relevance --metric score
```

Or compare them in SQL within version 1.

```sql
SELECT group_name, count(DISTINCT subject_id) AS subjects,
       avg((data->>'score')::double precision) AS mean_relevance
FROM statespace.logs
WHERE experiment_name = 'rank-v2' AND experiment_version = 1
  AND reason = 'assigned' AND outcome_name = 'relevance'
GROUP BY group_name;
```

Group rows use the name `atlas-search`; control rows use `control`. Check delivery and missing outcomes before interpreting this comparison.
