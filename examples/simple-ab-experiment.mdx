---
title: Simple A/B experiment
description: Compare one arm with its control.
---

This example gives 10% of the eligible US users of `atlas` the arm `recent-clicks`, and another 10% its control. The arm's search ranks results differently. The control runs the deployed ranking.

Start a branch from the default branch, and set the arm's settings in `statespace.toml`.

```shell
git switch -c exp/ranking/recent-clicks origin/main
```

```toml
app = "atlas"
share = 0.1
subject = 'request.headers["x-user-id"]'
eligibility = 'request.headers["cf-ipcountry"] == "US"'
```

Print the same line in the default and the arm.

```python
subject = request.headers["x-statespace-subject"]
print(json.dumps({
    "event": "click",
    "subject": subject,
    "position": 1,
}))
```

Push the branch and open a pull request with the hypothesis. When it is approved and can merge, the arm runs.

```shell
git push -u origin exp/ranking/recent-clicks
gh pr create --title "Rank by recent clicks" \
  --body "Sorted results should get more clicks."
```

Compare the arms within version 1.

```sql
SELECT arm, commit, count(DISTINCT subject_id) AS subjects,
       avg((data->>'position')::float) AS mean_position
FROM atlas.logs
WHERE experiment = 'ranking'
  AND experiment_version = 1
  AND reason IN ('assigned', 'arm-unavailable')
  AND data->>'event' = 'click'
GROUP BY arm, commit;
```

Arm rows use the name `recent-clicks`; control rows use `control`, with the arm's base as their commit. Check delivery and the sample ratio before interpreting this comparison.
