---
title: Simple A/B experiment
description: Compare one arm of the search app with its control, for 10% of US users each.
---

This example gives 10% of the eligible US users of `atlas` the arm `recent-clicks`, and another 10% its control. The arm ranks search results by recent clicks. The control runs the deployed ranking.

**Before you start:** set up the repository and run `ssp proxy`. See the [quickstart](/quickstart).

<Steps titleSize="h3">
  <Step title="Start the branch">
    Start the branch from the default branch.

    ```shell
    git switch -c exp/ranking/recent-clicks origin/main
    ```
  </Step>

  <Step title="Set the arm's settings">
    Set the share, the subject, and the eligible users.

    ```toml statespace.toml
    app = "atlas"
    share = 0.1
    subject = 'request.headers["x-user-id"]'
    eligibility = 'request.headers["cf-ipcountry"] == "US"'
    ```
  </Step>

  <Step title="Print the outcome">
    Print the same line in the default and in the arm.

    ```python
    subject = request.headers["x-statespace-subject"]
    print(json.dumps({
        "event": "click",
        "subject": subject,
        "position": 1,
    }))
    ```
  </Step>

  <Step title="Open the pull request">
    Push the branch, and open a pull request with the hypothesis.

    ```shell
    git push -u origin exp/ranking/recent-clicks
    gh pr create --title "Rank by recent clicks" \
      --body "Sorted results get more clicks."
    ```

    When the pull request can merge, the arm runs.
  </Step>

  <Step title="Compare the arms">
    Compare the arms in version 1.

    ```sql
    SELECT arm, commit,
           count(DISTINCT subject_id) AS subjects,
           avg((data->>'position')::float)
             AS mean_position
    FROM atlas.logs
    WHERE experiment = 'ranking'
      AND experiment_version = 1
      AND reason IN ('assigned', 'arm-unavailable')
      AND data->>'event' = 'click'
    GROUP BY arm, commit;
    ```
  </Step>
</Steps>

## Result

The query gives one row for `recent-clicks` and one for `control`. The `control` row has the arm's base as its commit. Before you read the comparison, check delivery and the sample ratio. See [Analyze the outcomes](/workflow/analyze-the-outcomes).
