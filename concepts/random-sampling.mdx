---
title: Eligibility
description: Select subjects with information in the request.
---

Eligibility defines the population that can enter an experiment. Use information that exists before treatment assignment.

Set a CEL eligibility rule over the request in the branch's `statespace.toml`.

```toml
eligibility = 'request.headers["cf-ipcountry"] == "US" && request.path.startsWith("/search")'
```

`ssp apply` validates the rule, also with `--dry-run`. `ssp proxy` evaluates the rule against each request's `method`, `path`, `query`, `headers`, and `cookies`. A header or cookie that is missing is `null`.

An eligible subject receives an arm: an arm of a branch, or a control. An ineligible subject receives the default and is recorded with `reason = 'ineligible'`. A rule that fails to evaluate is recorded with `reason = 'eligibility-error'`.

All arms of an experiment use the same eligibility rule. Do not use values that treatment can change.

```text
Suitable:   country, path, plan in a header set by your gateway
Unsuitable: response quality, post-treatment latency, conversion
```

Eligibility restricts the study population. It does not make that population a representative sample of all users. State this limit when interpreting the result.
