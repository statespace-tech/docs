---
title: Eligibility
description: Select the subjects who can enter an experiment.
---

Eligibility defines the population that can enter an experiment. Use only information that exists before treatment assignment.

```yaml
eligibility: 'context.country == "US" && context.plan == "pro"'
```

The SDK evaluates the CEL expression against the supplied JSON `context`.

```python
run = statespace.init("rank-v2")
config = run.get_config("u_42", context={"country": "US", "plan": "pro"})
```

An eligible subject receives control or a treatment. An ineligible subject receives `{}` and is recorded with `assigned = false` and `reason = 'ineligible'`.

```text
subject → eligibility → control or treatment
                    ↘ unassigned
```

Apply the same eligibility rule to every possible group. Do not use a value that the treatment can change.

```text
Suitable:   country, plan at assignment time, account type
Unsuitable: response quality, post-treatment latency, conversion
```
