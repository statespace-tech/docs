---
title: Eligibility
description: Select subjects with pre-treatment context.
---

Eligibility defines the population that can enter an experiment. Use information that exists before treatment assignment.

Create a draft with a CEL eligibility rule.

```shell
ssp experiment create rank-v2 --assignment user_id --group atlas-search=0.2 \
  --eligibility 'context.country == "US" && context.plan == "pro"'
```

The backend validates CEL when the draft changes. The SDK evaluates the rule against the supplied JSON context.

Provide every context value the rule reads.

```python
group = experiment.assign("u_42", context={"country": "US", "plan": "pro"})
```

An eligible subject receives control or a group. An ineligible subject receives the application's defaults and is logged with `reason = 'ineligible'`. A rule that fails to evaluate, for example on missing context, is logged with `reason = 'eligibility-error'`.

Apply the same eligibility rule to every group. Do not use values that treatment can change.

```text
Suitable:   country, plan at assignment time, account type
Unsuitable: response quality, post-treatment latency, conversion
```

Eligibility restricts the study population. It does not make that population a representative sample of all users. State this limit when interpreting the result.
