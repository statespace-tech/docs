---
title: Eligibility
description: Select subjects with pre-treatment context.
---

Eligibility defines the population that can enter an experiment. Use information that exists before treatment assignment.

Create a draft with a CEL eligibility rule.

```shell
ssp experiment create --name rank-v2 --assignment user_id   --eligibility 'context.country == "US" && context.plan == "pro"'   --variant atlas-search@1=0.2
```

The backend validates CEL when it creates the version. The SDK evaluates the rule against supplied JSON context.

Provide every context value required by the rule.

```python
rank = run.get_function(
    "u_42", context={"country": "US", "plan": "pro"},
    default=lambda items: items,
)
result = rank([3, 1, 2])
```

An eligible subject receives control or a candidate. An ineligible subject uses the application default and is logged with `assigned = false` and `reason = 'ineligible'`. Handle malformed context and evaluation errors in the application.

Apply the same eligibility rule to every possible group. Do not use values that treatment can change.

```text
Suitable:   country, plan at assignment time, account type
Unsuitable: response quality, post-treatment latency, conversion
```

Eligibility restricts the study population. It does not make that population a representative sample of all users. State this limit when interpreting the result.
