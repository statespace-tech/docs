[Statistical inference](https://en.wikipedia.org/wiki/Statistical_inference) uses observed data to estimate properties of a broader population. It turns experiment outcomes into evidence for a decision.

```text
outcomes → estimate → uncertainty → decision
```

## Estimands

An estimand states exactly which effect the experiment intends to estimate. It identifies the population, treatment, outcome, and summary measure.

```text
Among eligible search users, what is the average effect of atlas-search
assignment on clicks compared with the control arm of the deployed ranking?
```

An intention-to-treat estimand compares units by their random assignment. An exposure-based estimand compares units that received the condition. The second can lose the protection of random assignment when exposure is selective.

Define the estimand before selecting a statistical procedure. See [Treatment exposure](/concepts/outcome-measures#treatment-exposure) and [Forced assignment](/concepts/random-assignment#forced-assignment).

## Treatment effects

The [average treatment effect](https://en.wikipedia.org/wiki/Average_treatment_effect) is the difference between the expected outcome under treatment and control.

```text
ATE = mean outcome under treatment − mean outcome under control
```

Calculate the observed difference in PostgreSQL.

```sql
WITH variant_means AS (
  SELECT
    variant,
    avg((data->>'position')::double precision) AS mean_value
  FROM atlas.logs
  WHERE experiment = 'rank-v2'
    AND experiment_version = 1 AND reason IN ('assigned', 'variant-unavailable') AND data->>'event' = 'click'
  GROUP BY variant
)
SELECT
  max(mean_value) FILTER (WHERE variant = 'atlas-search')
    - max(mean_value) FILTER (WHERE variant = 'control') AS treatment_effect
FROM variant_means;
```

## Effect sizes

An [effect size](https://en.wikipedia.org/wiki/Effect_size) describes the magnitude of a difference. Report it in a unit that supports a product decision.

```text
absolute effect = treatment mean − control mean
relative effect = absolute effect / control mean
```

Always report the control value with a relative effect. A large relative change can represent a small absolute change.

## Statistical uncertainty

Every estimate contains sampling variation. Report a confidence interval or another uncertainty measure with the point estimate.

Estimate the standard error of a difference in means.

```sql
WITH variant_stats AS (
  SELECT
    variant,
    count(*) AS n,
    avg((data->>'position')::double precision) AS mean_value,
    stddev_samp((data->>'position')::double precision) AS standard_deviation
  FROM atlas.logs
  WHERE experiment = 'rank-v2'
    AND experiment_version = 1 AND reason IN ('assigned', 'variant-unavailable') AND data->>'event' = 'click'
  GROUP BY variant
)
SELECT
  treatment.mean_value - control.mean_value AS treatment_effect,
  sqrt(
    pow(treatment.standard_deviation, 2) / treatment.n
    + pow(control.standard_deviation, 2) / control.n
  ) AS standard_error
FROM variant_stats AS treatment
CROSS JOIN variant_stats AS control
WHERE treatment.variant = 'atlas-search'
  AND control.variant = 'control';
```

## Statistical power

[Statistical power](https://en.wikipedia.org/wiki/Statistical_power) is the probability that a test detects an effect of a specified size when that effect exists.

Power depends on these inputs:

- [Eligibility](/concepts/random-sampling)
- [Arm shares](/concepts/treatments-and-control-groups#arm-shares)
- The arms' shares of the app's subjects
- Outcome variance
- Minimum effect of interest
- Decision threshold

Do not stop an experiment only because an intermediate result looks favorable. Repeated inspection changes the error properties unless the analysis accounts for sequential decisions.

## Heterogeneous effects

An average effect can hide differences across populations. Estimate subgroup effects with pre-treatment attributes only when the sample supports them. Print the attribute in each line to analyze it.

```sql
SELECT
  data->>'country' AS country,
  variant,
  count(*) AS observations,
  avg((data->>'position')::double precision) AS mean_position
FROM atlas.logs
WHERE experiment = 'rank-v2'
  AND experiment_version = 1 AND reason IN ('assigned', 'variant-unavailable') AND data->>'event' = 'click'
GROUP BY country, variant;
```

Treat an unplanned subgroup result as exploratory. Confirm it with a new experiment.

## Practical significance

Statistical significance asks whether random variation can reasonably explain an estimate. Practical significance asks whether the effect is large enough to justify a decision.

Compare the estimated benefit with implementation cost, operational risk, and guardrail changes. A precise effect can still be too small to matter.
