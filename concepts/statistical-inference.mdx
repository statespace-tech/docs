title: Statistical inference

What do the outcomes say about the treatment? [Statistical inference](https://en.wikipedia.org/wiki/Statistical_inference) uses observed data to estimate properties of a larger population. In an experiment, it turns outcomes into an estimate, a measure of its uncertainty, and evidence for a decision.

## Estimands

An estimand states which effect the experiment estimates. It names the population, the treatment, the outcome, and the summary measure.

> Among eligible search users, what is the average effect of assignment to `recent-clicks` on clicks, compared with the control of the deployed ranking?

An intention-to-treat estimand compares subjects by their random assignment. An exposure-based estimand compares subjects that got the condition. The second can lose the protection of random assignment when exposure is selective.

Define the estimand before you choose a statistical procedure. See [Treatment exposure](/concepts/outcome-measures#treatment-exposure) and [Forced assignment](/concepts/random-assignment#forced-assignment).

## Treatment effects

The [average treatment effect](https://en.wikipedia.org/wiki/Average_treatment_effect) (ATE) is the difference between the expected outcome under treatment and under control.

```text
ATE = mean outcome under treatment
    − mean outcome under control
```

This query calculates the observed difference.

```sql
WITH arm_means AS (
  SELECT
    arm,
    avg((data->>'position')::float) AS mean_value
  FROM atlas.logs
  WHERE experiment = 'ranking'
    AND experiment_version = 1
    AND reason IN ('assigned', 'arm-unavailable')
    AND data->>'event' = 'click'
  GROUP BY arm
)
SELECT
  max(mean_value) FILTER (WHERE arm = 'recent-clicks')
    - max(mean_value) FILTER (WHERE arm = 'control')
    AS treatment_effect
FROM arm_means;
```

## Effect sizes

An [effect size](https://en.wikipedia.org/wiki/Effect_size) describes the size of a difference. Report it in a unit that supports a product decision.

```text
absolute effect = treatment mean − control mean
relative effect = absolute effect / control mean
```

Always report the control value with a relative effect. A large relative change can be a small absolute change.

## Statistical uncertainty

Each estimate includes sampling variation. Report a confidence interval, or another measure of uncertainty, with the point estimate. This query estimates the standard error of a difference in means.

```sql
WITH arm_stats AS (
  SELECT
    arm,
    count(*) AS n,
    avg((data->>'position')::float) AS mean_value,
    stddev_samp((data->>'position')::float) AS sd
  FROM atlas.logs
  WHERE experiment = 'ranking'
    AND experiment_version = 1
    AND reason IN ('assigned', 'arm-unavailable')
    AND data->>'event' = 'click'
  GROUP BY arm
)
SELECT
  treatment.mean_value - control.mean_value
    AS treatment_effect,
  sqrt(
    pow(treatment.sd, 2) / treatment.n
    + pow(control.sd, 2) / control.n
  ) AS standard_error
FROM arm_stats AS treatment
CROSS JOIN arm_stats AS control
WHERE treatment.arm = 'recent-clicks'
  AND control.arm = 'control';
```

## Statistical power

[Statistical power](https://en.wikipedia.org/wiki/Statistical_power) is the probability that a test finds an effect of a given size when that effect exists. Power depends on:

- The eligible population. See [Eligibility](/concepts/random-sampling).
- The arms' shares of the app's subjects. See [Arm shares](/concepts/treatments-and-control-groups#arm-shares).
- The variance of the outcome.
- The minimum effect of interest.
- The decision threshold.

<Warning>
  Do not stop an experiment only because an intermediate result looks good. Each look at the data changes the error rates, unless the analysis allows for sequential decisions.
</Warning>

## Heterogeneous effects

An average effect can hide differences between populations. Estimate subgroup effects with attributes from before the treatment, and only when the sample supports them. To analyze an attribute, print it in each line.

```sql
SELECT
  data->>'country' AS country,
  arm,
  count(*) AS observations,
  avg((data->>'position')::float) AS mean_position
FROM atlas.logs
WHERE experiment = 'ranking'
  AND experiment_version = 1
  AND reason IN ('assigned', 'arm-unavailable')
  AND data->>'event' = 'click'
GROUP BY country, arm;
```

Treat a subgroup result that you did not plan as exploratory. Confirm it with a new experiment.

## Practical significance

Statistical significance asks whether random variation can explain an estimate. Practical significance asks whether the effect is large enough for a decision.

Compare the benefit with the cost of the change, its operational risk, and its guardrails. A precise effect can still be too small to matter. To record the decision, see [Make a decision](/workflow/analyze-the-outcomes#make-a-decision).
