---
title: Treatments and control groups
description: Compare named groups of parameters with the application's defaults.
---

A treatment is the behavior being tested. A group is a named set of parameters that defines one treatment. Control supplies the comparison baseline.

## Interventions, treatments, and groups

This example changes search ranking with the group `atlas-search`.

```text
intervention: change search ranking
treatment:    the atlas-search group, which sets the ranker function and top_k
control:      the application's existing ranking code and values
```

A parameter is a function or a JSON value. Groups are versioned, and an experiment records which group version each of its versions used.

## Control group

The application supplies control with its current code and values.

```python
group = experiment.assign("u_42")
rank = group.function("ranker", rerank)
top_k = group.value("top_k", 20)
```

Control receives the weight not allocated to groups. It estimates what would happen without the tested change.

## Implicit control

Allocate 20% of eligible subjects to `atlas-search`.

```shell
ssp experiment create rank-v2 --group atlas-search=0.2
```

The remaining 80% belongs to control. Weights that total one leave no control group. Ineligible subjects also use the defaults, but their runs are not randomized control and must not be counted as control.

## Group weights

Weights must be greater than zero and total at most one.

```shell
ssp experiment update rank-v2 --group atlas-search=0.2 --group atlas-search-bm25=0.2
```

This split leaves 60% for control. Unequal weights change the sample size and statistical power of each comparison. See [Group allocation](/concepts/random-assignment#group-allocation) for stable assignment ranges.

## Treatment parameters

Set every parameter a treatment changes in its group.

```shell
ssp group create atlas-search ranker=rerank.py:score top_k=10
```

A group that leaves out a parameter uses the application's default for it. A parameter must have one type across the groups of an experiment. To test two changes and their interaction, give each combination its own group and analyze the full grid.
