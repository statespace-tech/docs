---
title: Random assignment
description: Produce stable groups across SDKs and service instances.
---

Random assignment gives each eligible subject one group within an immutable experiment version.

## Stable identity

Choose an identifier at the level where treatment can vary independently.

```yaml
assignment: user_id
```

Pass the identifier value when the application assigns the subject.

```python
run = statespace.init("rank-v2")
config = run.get_config("u_42", context={"country": "US"})
```

## Stable bucket

Each version has a random assignment salt. All SDKs use the same SHA-256 calculation.

```text
bucket = first 53 bits of SHA-256(assignment_salt + ":" + subject_id) / 2^53
```

Group weights occupy consecutive parts of the interval from `0` to `1`. The implicit control group occupies the remaining weight.

```text
control 0.0 ───────────── 0.8 | treatment 0.8 ── 1.0
```

The same subject, version, and salt produce the same assignment in Python, TypeScript, Go, and across service instances.

## New versions

A new version receives a new salt. It can assign a subject differently. Analyze each version separately.

```text
rank-v2 v1 → u_42 → control
rank-v2 v2 → u_42 → treatment
```
