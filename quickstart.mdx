In this tutorial, you run the experiment `checkout` on the app `shop-dev`. 5% of the subjects get the live commit, and 5% get your change.

## Use an agent

Give this prompt to your coding agent:

```text
Read https://statespace.com/skill.md and follow it.
```

The skill tells the agent how to set up Statespace, run experiments, and read the evidence. The agent uses your GitHub credential. See [Permissions](/concepts/how-it-works#permissions). To do the steps yourself, continue below.

## Prerequisites

- A GitHub repo, such as `acme/shop`, with a `Dockerfile` that has one `EXPOSE` port.
- A Linux machine with Docker and Docker Compose.
- The role Admin on the repo.

## Run your first experiment

<Steps>
  <Step title="Install the GitHub App">
    On [statespace.com](https://statespace.com), select **Connect GitHub**. Install the App on the account that owns the repo.
  </Step>

  <Step title="Write statespace.toml">
    Put this file in the root folder of the repo. Change the event to a route of your app.

    <StarterToml />
  </Step>

  <Step title="Build every push">
    Add this workflow. It builds each push and records the build.

    <BuildWorkflow />

    Commit both files, and push them to `main`.

    ```shell
    git add statespace.toml .github/workflows/build.yml
    git commit -m "Record builds with Statespace"
    git push
    ```
  </Step>

  <Step title="Add the app and a token">
    Install the CLI, and sign in with the same GitHub account. In the repo folder, add the app and a runtime token. The CLI shows the secret one time only.

    ```shell
    curl -fsSL https://statespace.com/install.sh | bash
    ssp login
    ssp app add shop-dev --note "shop on the dev machine"
    ssp token add --app shop-dev --note "Docker proxy"
    ```

    On the machine, put the secret in `.env`, next to `compose.yaml`.

    ```shell .env
    STATESPACE_TOKEN=<secret>
    ```
  </Step>

  <Step title="Run the proxy">
    On the machine, write `compose.yaml`. `shop` runs live, the build of `main`. `ssp` runs the proxy on port 80.

    ```yaml compose.yaml
    services:
      shop:
        image: ghcr.io/acme/shop@sha256:<digest>
        container_name: shop
        restart: unless-stopped

      ssp:
        image: ghcr.io/statespace-tech/statespace:0.5.1
        command:
          - proxy
          - docker
          - --live-container
          - shop
        environment:
          STATESPACE_TOKEN: ${STATESPACE_TOKEN}
        ports:
          - "80:8080"
        volumes:
          - /var/run/docker.sock:/var/run/docker.sock
        user: root
        restart: unless-stopped
        stop_grace_period: 30s
    ```

    Start the project, and point your traffic at port 80. See [Docker](/runtimes/docker) for the details.

    ```shell
    docker compose up -d
    ```
  </Step>

  <Step title="Push a change">
    Push a change on a new branch. CI builds and records it.

    ```shell
    git switch -c one-page-checkout
    git commit -am "Put checkout on one page"
    git push -u origin one-page-checkout
    ```
  </Step>

  <Step title="Set the arms">
    When the workflow is done, set the arms. `ssp app show` prints the live commit: use it in place of `c0ffee1`.

    ```shell
    ssp app show shop-dev
    ssp experiment update checkout --app shop-dev \
      --arm c0ffee1=0.05 \
      --arm "$(git rev-parse HEAD)=0.05"
    ```
  </Step>

  <Step title="Start the experiment">
    Start the experiment. The command waits until each arm is ready, for 5 minutes at most.

    ```shell
    ssp experiment start checkout --app shop-dev \
      --note "one-page checkout"
    ```
  </Step>

  <Step title="Read the evidence">
    Show the results of each arm: the latency, and the events of `statespace.toml`. Each arm's commit also has the status `statespace/shop-dev/checkout`.

    ```shell
    ssp experiment show checkout --app shop-dev
    ```

    For all other data, filter your own data tools, such as Datadog or Grafana, by `statespace.arm` or `service.version`, with the commit of the arm. See [Your own data tools](/guides/own-tools).
  </Step>

  <Step title="Stop the experiment">
    Stop the experiment. The arms leave traffic in seconds. To ship the change, merge it and deploy it as usual.

    ```shell
    ssp experiment stop checkout --app shop-dev \
      --note "enough data"
    ```
  </Step>
</Steps>
