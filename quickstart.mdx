---
title: Quickstart
description: Complete one experiment from YAML to SQL.
---

This quickstart tests reciprocal rank fusion for the `atlas-search` project. It uses one treatment, an implicit control, and a numeric relevance outcome.

<Steps>
  <Step title="Install the CLI">
    Install the current `ssp` binary on macOS or Linux.

    ```bash
    curl -fsSL https://statespace.com/install | bash
    ```

    Sign in when the CLI requests an account session.

    ```bash
    ssp login
    ```
  </Step>

  <Step title="Create the project">
    Create a globally named project that randomizes users.

    ```bash
    ssp project create --name atlas-search --unit user_id
    ```

    <Tip>
      The command shows the default read-write token once. Store it in a secret manager.
    </Tip>
  </Step>

  <Step title="Define the experiment">
    Save this definition as `experiment.yaml`.

    ```yaml
    name: rank-v2
    description: Test reciprocal rank fusion.

    sampling:
      traffic: 1.0

    assignment:
      method: random

    groups:
      - name: treatment
        weight: 0.20
        config:
          reranker: rrf
    ```

    <Note>
      Statespace adds an empty control group with the remaining weight of `0.80`.
    </Note>

    Create and start the experiment.

    ```bash
    ssp experiment create --project atlas-search --file experiment.yaml
    ssp experiment start --project atlas-search --name rank-v2
    ```
  </Step>

  <Step title="Apply the treatments">
    Install the Python SDK.

    ```bash
    uv add statespace-sdk
    ```

    Assign three users and record one relevance outcome for each run.

    ```python
    from statespace import Experiment

    experiment = Experiment.connect(
        "atlas-search/rank-v2",
        token="ssp_rw_7j...",
    )

    for user_id in ["u_42", "u_73", "u_91"]:
        run = experiment.run(user_id)
        reranker = run.config.get("reranker", None)
        result = search("query goes here", reranker=reranker)
        run.outcome("relevance", value=result.relevance)

    experiment.close()
    ```
  </Step>

  <Step title="Analyze the outcomes">
    Attach the project database through the DuckDB Quack protocol.

    ```sql
    ATTACH 'quack:atlas-search.db.statespace.app:443' AS statespace (
      TOKEN 'ssp_ro_7j...'
    );

    SELECT
      group_name,
      count(*) AS outcomes,
      avg(value) AS mean_relevance
    FROM statespace.outcomes
    WHERE experiment_name = 'rank-v2'
      AND name = 'relevance'
    GROUP BY group_name;
    ```

    <Info>
      This query describes the observed groups. Use the workflow pages before you make a production decision.
    </Info>
  </Step>
</Steps>

Continue with [Define the experiment](/workflow/define-the-experiment) to review each design decision.
