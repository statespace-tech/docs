---
title: Quickstart
description: Test a new search ranking on live traffic from a pull request, and read the result.
---

This example tests a branch of the search app `atlas` that ranks results by recent clicks. The branch is `exp/recent-clicks`, so the experiment is `recent-clicks`, with one arm.

<Steps>
  <Step title="Connect GitHub">
    On [statespace.com](https://statespace.com), select **Connect GitHub**. On GitHub's screen, pick your organization and the repositories that run experiments. One screen installs the Statespace GitHub App and signs you in. Your workspace takes the name of the organization.

    To use the terminal too, install `ssp` and sign in.

    ```shell
    curl -fsSL https://statespace.com/install.sh | bash
    ssp login
    ```
  </Step>

  <Step title="Merge the setup pull request">
    The App opens a pull request named "Set up Statespace" on each repository that you picked. It adds two files:

    - `statespace.toml`, which names the app after the repository and gives each arm 5% of its subjects.
    - `.github/workflows/statespace.yml`, which builds each push to an `exp/` branch from your `Dockerfile`, pushes the image to GitHub Packages, and records it.

    The description lists one more step. In the workflow that builds production, add this step after the build, so that Statespace knows the commit of each production image:

    ```yaml
    - uses: statespace-tech/action@v1
      with:
        image: ghcr.io/acme/atlas@${{ steps.build.outputs.digest }}
    ```

    Merge the pull request. In branch protection for `main`, require one approval. If the App did not open the pull request, open it from the checklist on the **Apps** page of the dashboard.

    To let your coding agent do the next steps, give it this prompt:

    ```text
    Read https://statespace.com/skill.md and follow it.
    ```
  </Step>

  <Step title="Print what you measure">
    Statespace records each line that an arm prints, with its arm. To compare subjects, print a JSON line with a `subject` field. The proxy sets the `x-statespace-subject` header to the subject from your rule, or to the browser ID.

    ```python
    subject = request.headers["x-statespace-subject"]
    print(json.dumps({"event": "click", "subject": subject, "position": 1}))
    ```

    Deploy this change to production as usual, so the default and every arm print the same lines.
  </Step>

  <Step title="Run the proxy">
    Create a runtime token and store it as `SSP_TOKEN` where the app runs. Then run the app behind `ssp proxy`. On a machine with Docker, it runs your deployed image and each arm as containers, and routes each user.

    ```shell
    ssp token create --name production --preset runtime
    ssp proxy --app atlas --image ghcr.io/acme/atlas:main --health /health
    ```

    On Kubernetes, run it beside the app in each pod instead. See [Deployment](/getting-started/deployment).
  </Step>

  <Step title="Open a pull request">
    Start a branch named `exp/<name>`, change the ranking, and set the arm's share in `statespace.toml`. To compare more arms in one experiment, name the branches `exp/<experiment>/<arm>`.

    ```toml
    app = "atlas"
    share = 0.1
    subject = 'request.headers["x-user-id"]'
    ```

    ```shell
    git switch -c exp/recent-clicks
    git commit -am "Rank results by recent clicks"
    git push -u origin exp/recent-clicks
    gh pr create --fill
    ```

    CI publishes the commit. When a reviewer approves the pull request and GitHub says that it can merge, 10% of the subjects get the branch, and another 10% get the control. The `statespace/arm` check on the pull request tells what runs.
  </Step>

  <Step title="Read the results">
    Create a token that reads the app in SQL. The output shows its database URL.

    ```shell
    ssp token create --name analyst --preset analyst --app atlas
    ```

    Compare the share of subjects who clicked in each arm.

    ```sql
    SELECT arm, commit,
           count(DISTINCT subject_id) AS subjects,
           count(DISTINCT subject_id) FILTER (WHERE data->>'event' = 'click') AS clicked
    FROM atlas.logs
    WHERE experiment = 'recent-clicks' AND reason IN ('assigned', 'arm-unavailable')
    GROUP BY arm, commit;
    ```

    To stop the arm, make the pull request a draft, or run `ssp stop` with its URL. To ship it, merge it.

    ```shell
    ssp stop https://github.com/acme/atlas/pull/418
    ```
  </Step>
</Steps>
