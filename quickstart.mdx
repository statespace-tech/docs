---
title: Quickstart
description: Complete one experiment from YAML to SQL.
---

This example tests reciprocal rank fusion for eligible US users.

<Steps>
  <Step title="Install and sign in">
    Install the CLI, then sign in with GitHub or Google.

    ```shell
    curl -fsSL https://statespace.com/install | bash
    ssp login
    ```
  </Step>

  <Step title="Define the experiment">
    Save this definition as `experiment.yaml`.

    ```yaml
    name: rank-v2
    description: Test reciprocal rank fusion.
    assignment: user_id
    eligibility: 'context.country == "US"'
    groups:
      - name: treatment
        weight: 0.2
        config:
          reranker: rrf
    ```

    Control is implicit. It receives the remaining `0.8` weight and an empty configuration.
  </Step>

  <Step title="Create and start version 1">
    Create the draft, then start it explicitly.

    ```shell
    ssp experiment create --file experiment.yaml
    ssp experiment start --name rank-v2
    ```
  </Step>

  <Step title="Create an SDK token">
    Store the returned secret as `STATESPACE_TOKEN` in the application.

    ```shell
    ssp token create --name production
    export STATESPACE_TOKEN=ssp_token_7j...
    ```
  </Step>

  <Step title="Run the experiment">
    Install the Python SDK and reference the remote experiment by name.

    ```shell
    pip install statespace-sdk
    ```

    Assign a subject and record one JSON outcome.

    ```python
    import statespace

    with statespace.init("rank-v2") as run:
        config = run.get_config("u_42", context={"country": "US"})
        reranker = config.get("reranker")
        run.log({"relevance": 0.7})
    ```
  </Step>

  <Step title="Query the result">
    Query the account database through the CLI.

    ```shell
    ssp query 'SELECT experiment_version, group_name, data FROM statespace.logs'
    ```
  </Step>
</Steps>
