Statespace manages A/B tests for applications and AI systems. The CLI publishes experiment definitions. Language SDKs assign subjects and record JSON results.

```text
experiment.yaml → ssp CLI → SDK assignment → JSON outcomes → PostgreSQL
```

## Interfaces

Each interface has one responsibility.

| Interface | Responsibility |
| --- | --- |
| `ssp` CLI | Creates versions, starts experiments, and manages credentials. |
| SDK | Caches configurations, assigns subjects, and records JSON events. |
| PostgreSQL | Stores one isolated account database and exposes `statespace.logs`. |

The Python, TypeScript, and Go SDKs use the same stable assignment algorithm.

```text
Python:     statespace-sdk
TypeScript: @statespace-tech/sdk
Go:         github.com/statespace-tech/go-sdk
```
