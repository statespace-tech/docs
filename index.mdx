Statespace runs A/B tests on the functions and values of live software. Groups hold candidate functions, prompts, and settings. Experiments send a share of real traffic to each group, and SDKs record what happened.

```text
ssp group → ssp experiment → SDK assignment → JSON outcomes → results and SQL
```

## Interfaces

Each interface has one responsibility.

| Interface | Responsibility |
| --- | --- |
| `ssp` CLI | Defines groups, builds functions, runs experiments, and reads results. |
| SDK | Caches configurations, assigns subjects, reads parameters, and records outcomes. |
| PostgreSQL | Stores one isolated account database and exposes `statespace.logs`. |

The Python, TypeScript, and Go SDKs use the same stable assignment algorithm.

```text
Python:     statespace-sdk
TypeScript: @statespace-tech/sdk
Go:         github.com/statespace-tech/go-sdk
```
