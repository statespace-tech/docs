Statespace A/B tests whole versions of an app in production. A variant is a signed build of your app, usually a branch. `ssp host` runs it beside the version you deployed, sends a share of real subjects to it, and records what they do.

```text
ssp variant create → ssp experiment start → ssp host routes subjects → outcomes → results and SQL
```

## Interfaces

Each interface has one responsibility.

| Interface | Responsibility |
| --- | --- |
| `ssp` CLI | Defines apps, publishes variants, runs experiments, and reads results. |
| `ssp host` | Runs your app and its variants, assigns each request's subject, and records events. |
| PostgreSQL | Stores one isolated account database, with one schema of views per app. |

Your app needs no SDK. It reports outcomes by printing a JSON line.

```python
print(json.dumps({"statespace": "click", "subject": subject, "position": 1}))
```
