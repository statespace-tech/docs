## Headless experimentation

Statespace provides a CLI, SDKs, and a SQL database instead of a fixed dashboard. Your coding agent can use each interface directly.

| Interface | Purpose |
| --- | --- |
| YAML | Defines sampling, assignment, and groups. |
| CLI | Shows the account and manages tokens, layers, and experiment state. |
| SDK | Creates experiments, assigns subjects, and records outcomes. |
| DuckDB | Queries raw experiment data with SQL. |

## Coding-agent workflow

The platform separates experiment evidence from the analysis that uses it.

<Steps>
  <Step title="Define the experiment">
    Write the hypothesis and configuration in a reviewable YAML file.
  </Step>
  <Step title="Apply the treatments">
    Use an SDK to assign units and apply the selected configuration.
  </Step>
  <Step title="Monitor the data">
    Check delivery, sampling traffic, group balance, and guardrails.
  </Step>
  <Step title="Analyze the outcomes">
    Query raw data and estimate treatment effects with DuckDB.
  </Step>
  <Step title="Make a decision">
    Record the evidence, action, and follow-up experiment.
  </Step>
</Steps>

## Direct SQL analysis

Each account publishes one DuckDB database through the Quack protocol. The database contains experiment definitions, assignments, runs, outcomes, and the `logs` view.

```sql
SELECT
  group_name,
  avg(data.relevance::DOUBLE) AS mean_relevance
FROM statespace.logs
WHERE experiment_name = 'rank-v2'
GROUP BY group_name;
```

<Info>
  A coding agent can inspect the schema, write a query, test an assumption, and revise the analysis without a dashboard-specific API.
</Info>

## Data ownership

Your account database keeps the raw evidence behind every aggregate. You can query and download it with a database token.

- Statespace does not train on account data.
- Statespace does not share account data.
- Data retention follows the account plan.
- Revoked tokens lose access immediately.

## Product scope

Statespace guarantees who received what, when, and why. Your team remains responsible for the hypothesis, metric definitions, statistical method, and final decision.
