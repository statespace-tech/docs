Statespace A/B tests whole versions of your app in production. A pull request of a branch named `exp/<name>` is an experiment. While GitHub says that the pull request can merge, `ssp proxy` sends a share of real subjects to the branch. The same share goes to a control: the version that the branch started from. Every line the arms print goes to your PostgreSQL database.

1. Connect GitHub, and merge the "Set up Statespace" pull request.
2. Push an `exp/` branch, and open a pull request. CI records each commit with `ssp apply`.
3. When the pull request can merge, `ssp proxy` routes a share of the subjects to the arm.
4. The arm prints lines. Compare the arms in SQL.
